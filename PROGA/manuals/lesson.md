## 📘 Лекция 1: Основы языка программирования Си

Лекция охватывает базовые элементы языка Си, включая его алфавит, правила именования, типы данных, операции и ввод/вывод, а также пример программирования линейного алгоритма.

-----

## 1\. Базовые Элементы Языка Си

### 1.1. Алфавит и Идентификаторы (Имена)

#### 📝 Алфавит Языка Си

Алфавит определяет набор символов, которые могут быть использованы для написания программ. В него входят:

  * **Буквы:** Прописные (A-Z) и строчные (a-z) буквы латинского алфавита.
  * **Цифры:** Арабские цифры (0-9).
  * **Специальные знаки:**
    ```
    " , {} | [ ] ( ) + - / % \ ; ' . : ? < = > _ ! & * # ~ ^
    ```
  * **Неизображаемые символы (пробельные):** Пробел, табуляция, символ новой строки (перевод строки).

#### 🏷️ Идентификаторы (Имена)

**Идентификатор** — это имя, используемое для обозначения переменных, функций, меток и других элементов программы.

  * **Правила формирования:** Идентификатор представляет собой последовательность букв, цифр и символов подчеркивания (\_).
  * **Правило начала:** Идентификатор **должен** начинаться с буквы или символа подчеркивания (\_).
    > **Примеры:** `Lab_1`, `size22`, `_min`, `TIME`, `time`.
  * **Чувствительность к регистру (Case Sensitivity):** Си — **регистрозависимый** язык. Это означает, что **прописные и строчные буквы различаются**. Идентификаторы `TIME` и `time` считаются разными.
  * **Длина:** Компилятор Си обычно гарантирует уникальность первых **31** символа идентификатора (хотя в современных стандартах это значение может быть больше).

## 2\. Переменные и Типы Данных

### 2.1. Переменные

**Переменная** — это именованная область памяти, предназначенная для хранения данных определенного типа.

  * **Характеристика:** Отличительная особенность переменной — возможность связывать с её именем **различные значения** в ходе выполнения программы.
  * **Определение (Декларация):** Каждая переменная **должна быть определена** (декларирована) перед её использованием в программе. При определении для неё выделяется участок памяти.
  * **Тип переменной:** Определяет, какие значения может принимать переменная, и как эти значения хранятся в памяти. **Размер выделяемого участка памяти зависит от типа переменной.**

### 2.2. Основные Типы Данных

Размеры и диапазоны значений могут незначительно варьироваться в зависимости от конкретной архитектуры и компилятора, но следующие значения являются типичными или минимально гарантированными (в соответствии со стандартами):

| Тип | Размер (Базовая архитектура) | Диапазон (Типичный или Минимальный) | Назначение |
| :--- | :--- | :--- | :--- |
| **Целые числа** | | | |
| `char` | 1 байт | $-128$ до $127$ | Символы или малые целые |
| `unsigned char` | 1 байт | $0$ до $255$ | Беззнаковые малые целые |
| `short` / `int` | $2$ / $4$ байта | $-32768$ до $32767$ (для 2 байтов) | Основной целочисленный тип |
| `unsigned int` | $2$ / $4$ байта | $0$ до $65535$ (для 2 байтов) | Беззнаковые целые |
| `long` | 4 или 8 байтов | $\approx -2 \times 10^9$ до $\approx 2 \times 10^9$ (для 4 байтов) | Большие целые |
| `unsigned long` | 4 или 8 байтов | $0$ до $\approx 4 \times 10^9$ (для 4 байтов) | Беззнаковые большие целые |
| **Вещественные (Плавающая точка)** | | | |
| `float` | 4 байта | $\pm 3.4 \times 10^{-38}$ до $\pm 3.4 \times 10^{+38}$ | Одинарная точность |
| `double` | 8 байтов | $\pm 1.7 \times 10^{-308}$ до $\pm 1.7 \times 10^{+308}$ | Двойная точность (рекомендуется для вычислений) |
| `long double` | 10 или 16 байтов | Больший диапазон и точность | Расширенная точность |

> **Примечание:** В современных 32/64-битных системах **`int`** чаще всего занимает **4 байта** ($-2147483648$ до $2147483647$).

## 3\. Операции и Выражения

Операции используются для выполнения действий над переменными и значениями.

### 3.1. Основные Операции

| Категория | Операция | Описание | Пример |
| :--- | :--- | :--- | :--- |
| **Присваивание** | `=` | Присвоить значение (справа налево) | `a = 5;` |
| **Арифметические** | `+`, `-` | Сложение, вычитание | `x + y` |
| | `*`, `/` | Умножение, деление | `x * y` |
| | `%` | **Остаток от деления** (только для целых чисел) | `5 % 2 = 1` |
| **Отношения** | `==` | Равно ли | `a == b` |
| | `!=` | Не равно ли | `a != b` |
| | `<`, `>`, `<=`, `>=` | Меньше, больше, меньше/равно, больше/равно | `a < 10` |
| **Логические** | `&&` | Логическое **И** (AND) | `(a > 0) && (b < 10)` |
| | `\|\|` | Логическое **ИЛИ** (OR) | `(a == 5) \|\| (a == 7)` |
| | `!` | Логическое **НЕ** (NOT) | `! (a == b)` |

### 3.2. Операции Модификации и Инкремент/Декремент

| Операция | Название | Эквивалент | Описание |
| :--- | :--- | :--- | :--- |
| `+=` | Присваивание после сложения | `a = a + b` | `a += b;` |
| `-=` | Присваивание после вычитания | `a = a - b` | `a -= b;` |
| `*=` | Присваивание после умножения | `p = p * 2` | `p *= 2;` |
| `/=` | Присваивание после деления | `p = p / 2` | `p /= 2;` |
| `%=` | Присваивание после деления по модулю | `n = n % 3` | `n %= 3;` |
| **Постфиксный** `++`, `--` | Инкремент/Декремент | `a = a + 1` | `a++` / `a--`. Значение **сначала используется**, **затем** изменяется. |
| **Префиксный** `++`, `--` | Инкремент/Декремент | `a = a + 1` | `++a` / `--a`. Значение **сначала изменяется**, **затем** используется. |

## 4\. Операторы Ввода/Вывода

Стандартные операции ввода/вывода в Си реализуются функциями **`printf()`** и **`scanf()`**, доступными при подключении заголовочного файла **`<stdio.h>`** (Standard Input/Output).

### 4.1. Оператор Вывода: `printf()`

Используется для вывода форматированных данных на стандартное устройство вывода (обычно экран).

```c
printf(<форматная строка>, список_переменных);
```

#### 📌 Форматная строка

Включает:

1.  **Текст:** Выводится "как есть".
2.  **Спецификаторы формата:** Определяют тип данных для вывода. Начинаются с символа `%`.
3.  **Управляющие символы:** Непечатаемые символы для управления курсором.

#### 📄 Спецификаторы Формата (Основные)

| Формат | Тип данных | Описание |
| :--- | :--- | :--- |
| `%c` | `char` | Символ |
| `%d` / `%i` | `int` | Целое десятичное (со знаком) |
| `%u` | `unsigned int` | Беззнаковое целое |
| `%o` | `int` | Восьмеричное целое |
| `%x` / `%X` | `int` | Шестнадцатеричное целое (строчные/прописные) |
| `%s` | Массив `char` (строка) | Строка |
| `%f` | `float`, `double` | Вещественное число с фиксированной точкой |
| `%e` / `%E` | `float`, `double` | Вещественное число в экспоненциальной форме |
| `%g` / `%G` | `float`, `double` | Более компактный вывод (`%f` или `%e`) |

#### 🔧 Модификаторы Формата (внутри спецификатора)

Синтаксис: `  %[флаг] [ширина] [.точность] [l] тип `

  * **`[ширина]`:** Минимальный размер поля вывода.
  * **`.точность`:** Для вещественных чисел — **количество знаков после десятичной точки**.
  * **`l`:** Используется для указания, что выводится `long` (например, `%ld`, `%lf` для `long double`).

#### ⌨️ Управляющие Символы (Escape-последовательности)

| Символ | Описание |
| :--- | :--- |
| `\n` | **Перевод строки** |
| `\t` | Горизонтальная табуляция |
| `\v` | Вертикальная табуляция |
| `\b` | Возврат на 1 символ (Backspace) |
| `\r` | Возврат каретки (на начало строки) |
| `\a` | Звуковой сигнал (Alert) |
| `\\` | Обратный слэш |
| `\"` | Двойная кавычка |

### 4.2. Оператор Ввода: `scanf()`

Используется для чтения форматированных данных со стандартного устройства ввода (обычно клавиатуры).

```c
scanf(<форматная строка>, адрес_переменной_1, адрес_переменной_2, ...);
```

  * **Форматная строка:** В отличие от `printf()`, обычно содержит **только спецификаторы формата** (например, `"%d %f"`).
  * **Адреса переменных:** Перед именем большинства переменных (кроме строк и массивов) должен стоять оператор **взятия адреса** (**`&`**). Это необходимо, чтобы `scanf()` мог записать полученное значение непосредственно в ячейку памяти, выделенную для переменной.
    > **Пример:** `scanf ("%f%f", &c, &x);`

## 5\. Программирование Алгоритма Линейной Структуры

**Линейный алгоритм** — это последовательность действий, выполняемых одно за другим, без условий и циклов. Чаще всего используется для вычислений по формулам.

### 5.1. Стандартные Математические Функции

Для использования большинства математических функций необходимо подключить заголовочный файл **`<math.h>`**. Аргументы и возвращаемые значения этих функций обычно имеют тип **`double`**.

| Функция | Описание | Функция | Описание |
| :--- | :--- | :--- | :--- |
| `sin(x)` | $\sin x$ | `log(x)` | Натуральный логарифм ($\ln x$) |
| `cos(x)` | $\cos x$ | `log10(x)` | Десятичный логарифм ($\lg x$) |
| `tan(x)` | $\operatorname{tg} x$ | `exp(x)` | Экспонента ($e^x$) |
| `sqrt(x)` | Корень квадратный ($\sqrt{x}$) | `pow(x, y)` | $x$ в степени $y$ ($x^y$) |
| `abs(x)` / `fabs(x)` | Модуль $x$ (`abs` для `int`, `fabs` для `float`/`double`) | `acos(x)`, `asin(x)`, `atan(x)` | Обратные тригонометрические функции |

> **Важно:** Для тригонометрических функций (`sin`, `cos`, `tan` и т.д.) аргумент $x$ должен быть задан в **радианах**.

### 5.2. Пример Программы

**Задача:** Вычислить площадь ($S$) и катеты ($a, b$) прямоугольного треугольника, если известны гипотенуза $c$ и угол $x$ (в градусах).

**Формулы:**
$$a = c \times \sin x$$
$$b = c \times \cos x$$
$$S = \frac{a \times b}{2}$$

[Image of a right-angled triangle labeled with sides a, b, c and angle x]

```c
// Вычисление сторон и площади прямоугольного треугольника
// По известным гипотенузе 'c' и углу 'x' (в градусах)

#include <stdio.h>  // Для функций ввода/вывода: printf, scanf
#include <math.h>   // Для математических функций: sin, cos

int main()
{
    // Определение вещественных переменных
    float a, b, c, x, S; 
    
    // Ввод исходных данных
    printf("\n Введите гипотенузу c и угол x (в градусах): ");
    scanf("%f%f", &c, &x);
    
    // Перевод угла из градусов в радианы: x_rad = x_deg * PI / 180
    x = x / 180.0 * 3.14159265; 
    
    // Вычисление катетов и площади
    a = c * sin(x);
    b = c * cos(x);
    S = a * b / 2.0;
    
    // Вывод результатов (формат: %7.2f - всего 7 позиций, 2 знака после точки)
    printf("\n Результат: a=%7.2f   b=%7.2f   c=%7.2f   S=%7.2f \n", a, b, c, S);
    
    return 0; // Возврат из функции main (успешное завершение)
}
```

### 5.3. Структура Программы на Си

  * **Комментарии:** Используются для пояснения кода.
      * **Однострочный:** Начинается с **`//`** и продолжается до конца строки.
      * **Многострочный:** Заключается в пару символов **`/* ... */`**.
  * **Директивы препроцессора (`#include`):** Предписывают компилятору включить содержимое заголовочного файла (библиотеки) в программу.
      * `#include <stdio.h>`: Доступ к функциям стандартного ввода-вывода (`printf`, `scanf`).
      * `#include <math.h>`: Доступ к математическим функциям (`sin`, `cos`, `pow` и т.д.).
  * **Функция `main()`:** Является **обязательной** и служит **точкой входа** в программу.
      * **Круглые скобки `()`:** Обязательны (даже если список параметров пуст).
      * **Фигурные скобки `{}`:** Заключают **тело функции** (составной оператор), где находятся выполняемые инструкции.
  * **Операторы:** Завершаются точкой с запятой (**`;`**).
  * **Оператор `return`:** Используется для выхода из функции, часто с возвратом значения (например, `0` для успешного завершения программы из `main`).

## 🚀 Лекция 2: Разветвляющиеся Алгоритмы и Условные Операторы в Си

Эта лекция посвящена управлению ходом выполнения программы с помощью условных конструкций, позволяющих реализовать **разветвляющиеся алгоритмы**.

-----

## 1\. Концепция Разветвляющихся Алгоритмов

### 1.1. Определение и Цель

**Разветвляющийся алгоритм** — это алгоритм, в котором вычислительный процесс (или последовательность действий) осуществляется не линейно, а по **одной из нескольких ветвей** в зависимости от выполнения определенного условия.

  * **Цель:** Приобретение практических навыков в составлении алгоритмов и программ, способных принимать решения и выполнять различные действия в зависимости от входных данных или промежуточных результатов.

Если необходимо выбрать из **двух** вариантов, используется **условный оператор** (`if`). Если вариантов **больше двух** (множественный выбор), часто применяется оператор **переключения** (`switch`) или вложенные `if...else if` конструкции.

### 1.2. Логические Операторы (Краткое Повторение)

При формировании сложных условий используются логические операторы:

  * **`&&`** — Логическое **И** (AND). Результат истинен (не ноль), только если **оба** операнда истинны.
  * **`||`** — Логическое **ИЛИ** (OR). Результат истинен, если **хотя бы один** операнд истинен.
  * **`!`** — Логическое **НЕ** (NOT). Инвертирует логическое значение операнда.

> В языке Си **истина** представлена любым ненулевым значением, а **ложь** — значением **0**.

-----

## 2\. Условный Оператор `if`

Условный оператор `if` является основным средством реализации ветвления в языке Си.

### 2.1. Формат Оператора `if`

#### Полная форма (С двумя ветвями)

Используется для выбора из двух взаимоисключающих вариантов.

```c
if (условие)
    оператор_1; // Выполняется, если условие истинно (не равно 0)
else
    оператор_2; // Выполняется, если условие ложно (равно 0)
```

#### Сокращенная форма (С одной ветвью)

Используется, если действие требуется выполнить только при истинности условия.

```c
if (условие)
    оператор_1; // Выполняется, если условие истинно
// Дальше идет остальной код программы
```

### 2.2. Правила Использования Блоков

Условие всегда должно быть заключено в **круглые скобки** `()`.

  * **Один оператор:** Если `оператор_1` или `оператор_2` состоит только из **одного оператора**, фигурные скобки `{}` **не обязательны** (как в форматах выше).
  * **Составной оператор (Блок):** Если требуется выполнить **несколько операторов** в одной ветви (`оператор_1` и/или `оператор_2`), они должны быть заключены в **фигурные скобки** `{}`. Это называется **блоком операторов** или **составным оператором**.

<!-- end list -->

```c
// Пример использования составного оператора
if (x > 0) {
    x = x * 2;
    printf("Число удвоено.\n");
} else {
    x = 0;
    printf("Число сброшено в ноль.\n");
}
```

### 2.3. Пример: Нахождение Максимума (Итеративный Подход)

Данный пример демонстрирует, как с помощью последовательных `if` операторов найти наибольшее значение из трех вычисленных функций.

```c
// ...
    float x, y1, y2, y3, max;
    
    printf("Input x ");
    scanf("%f", &x);
    
    // 1. Вычисление значений функций
    y1 = x * x + 1; 
    y2 = 7 - x * x; 
    y3 = x + 1;
    
    // 2. Инициализация максимума первым значением
    max = y1;
    
    // 3. Последовательная проверка и обновление максимума
    if (y2 > max)
        max = y2;
    
    if (y3 > max)
        max = y3; 
    
    printf("x=%8.2f y1=%8.2f y2=%8.2f y3=%8.2f max=%8.2f \n", x, y1, y2, y3, max);
// ...
```

## 3\. Условная Тернарная Операция (`? :`)

### 3.1. Формат и Принцип Работы

**Условная тернарная операция** (или **трехместная операция**) — это краткий способ записи условного выражения, возвращающего значение. Она является единственной тернарной операцией в Си, то есть требует **три** операнда.

**Формат:**

```c
выражение_1 ? выражение_2 : выражение_3
```

**Принцип:**

1.  Сначала вычисляется **`выражение_1`** (условие).
2.  Если `выражение_1` истинно (т.е. **не равно 0**), то результатом всей операции становится значение **`выражение_2`**.
3.  Если `выражение_1` ложно (т.е. **равно 0**), то результатом всей операции становится значение **`выражение_3`**.

### 3.2. Примеры Использования

#### Нахождение абсолютного значения

```c
// Эквивалентно: if (x < 0) x = -x; else x = x;
x = x < 0 ? -x : x;
```

#### Нахождение максимума (Вложенный тернарный оператор)

Условная операция может быть вложена. В следующем примере она используется для нахождения максимума из трех переменных, что часто применяется для компактной записи:

```c
// Сначала ищется максимум между y2 и y3: (y2>y3 ? y2 : y3)
// Затем этот максимум сравнивается с y1.
max = y1 > y2 && y1 > y3 ? y1 : (y2 > y3 ? y2 : y3);

// Более наглядный, хотя менее эффективный подход, если y1 не самый большой:
// max = (y1 > y2) ? ((y1 > y3) ? y1 : y3) : ((y2 > y3) ? y2 : y3);
```

### 3.3. Пример: Нахождение Максимума (С помощью тернарного оператора)

Использование тернарной операции для нахождения наибольшего значения из трех вычисленных функций.

```c
// ...
    float x, y1, y2, y3, max;
    
    printf("Input x ");
    scanf("%f", &x);
    
    y1 = x * x + 1; 
    y2 = 7 - x * x; 
    y3 = x + 1;
    
    // Использование вложенной тернарной операции для нахождения максимума
    max = y1 > y2 ? (y1 > y3 ? y1 : y3) : (y2 > y3 ? y2 : y3);
    
    printf("x=%8.2f y1=%8.2f y2=%8.2f y3=%8.2f max=%8.2f\n", x, y1, y2, y3, max);
// ...
```

## 4\. Множественный Выбор (Введение)

Для реализации алгоритмов с **более чем двумя ветвями** (множественный выбор) используются следующие структуры:

### 4.1. Конструкция `if-else if-else`

Эта структура позволяет проверить последовательно несколько условий, пока одно из них не окажется истинным.

```c
if (условие_1) {
    // Операторы для ветви 1
} else if (условие_2) {
    // Операторы для ветви 2
} else if (условие_N) {
    // Операторы для ветви N
} else {
    // Операторы для ветви по умолчанию (если ни одно условие не истинно)
}
```

### 4.2. Оператор `switch` (Переключение)

Оператор `switch` используется для выбора одного из множества вариантов выполнения кода на основе значения целочисленного или символьного выражения.

```c
switch (выражение) {
    case константа_1:
        // Операторы для ветви 1
        break; // Обязателен для выхода!
    case константа_2:
        // Операторы для ветви 2
        break;
    default:
        // Операторы по умолчанию (если ни один case не совпал)
}
```

## 🎯 Лекция 3: Множественный Выбор и Оператор `switch`

Эта лекция посвящена реализации **алгоритмов множественного ветвления** с использованием оператора **`switch`** в языке Си.

-----

## 1\. Оператор Множественного Выбора `switch`

### 1.1. Назначение

Оператор **`switch`** (переключатель) используется для сравнения значения одного **выражения** с рядом предопределенных **целочисленных констант** (меток) и выполнения соответствующего блока кода. Это наиболее структурированный способ реализации алгоритмов, где необходимо выбрать одно действие из множества возможных.

  * **Цель:** Приобретение практических навыков в составлении программ, реализующих множественное ветвление.

### 1.2. Общий Формат `switch`

```c
switch (выражение) 
{ 
    case метка_1: 
        список_операторов_1; 
        // Обычно здесь ставится break;
        
    case метка_2: 
        список_операторов_2; 
        break; 

    // ... дополнительные case-ветви
    
    default: 
        операторы_по_умолчанию; 
        // break; здесь не нужен, т.к. это конец switch
}
```

### 1.3. Ключевые Правила и Компоненты

  * **Выражение:** Должно иметь **целочисленный тип** (включая `char`, `short`, `int`, `long`, `enum`). Значения с плавающей точкой (`float`, `double`) использовать нельзя.
  * **Метки (`case`):**
      * Должны быть **целочисленными константами** (литералами или константными выражениями).
      * Каждая метка должна быть **уникальной** внутри одного `switch`.
      * После метки ставится двоеточие (`:`).
  * **Оператор `break`:**
      * Ключевое слово `break` служит для **прерывания** выполнения оператора `switch` и **перехода** к оператору, следующему за закрывающей фигурной скобкой `}`.
      * **В случае отсутствия `break`** (так называемое "проваливание" — **fall-through**), программа продолжит выполнение операторов следующей ветви `case`, пока не встретит `break` или не достигнет конца `switch`.
  * **Метка `default`:**
      * Ветвь **`default`** является **необязательной**.
      * Она выполняется, если значение `выражения` **не совпало** ни с одной из меток `case`.
      * Обычно ставится в конце, но может быть расположена в любом месте внутри `switch`.

-----

## 2\. Примеры Использования и "Проваливание" (`fall-through`)

### 2.1. Определение Количества Дней в Месяце

В этом примере используется эффект **проваливания** (отсутствие `break` между метками) для группировки месяцев с одинаковым числом дней.

```c
#include <stdio.h> // stdio.h для printf/scanf

int main(int argc, char *argv[])
{   
    int m; // Переменная для номера месяца
    int days;
    
    printf("\n Введите номер месяца (1-12): ");
    scanf("%d", &m);
    
    switch (m)
    {
        // 1. Группа месяцев с 31 днем. 
        // Отсутствие break позволяет выполнить код только для последней метки.
        case 1:
        case 3:
        case 5: 
        case 7:
        case 8:
        case 10:
        case 12:
            days = 31;
            break; // Обязателен, чтобы не попасть в case 2
            
        case 4: 
        case 6: 
        case 9: 
        case 11: 
            days = 30;
            break;
            
        case 2: 
            // Обратите внимание: для упрощения не учитывается високосный год.
            days = 28;
            break;
            
        default: 
            days = -1; // Используем -1 как код ошибки
            printf("\n Error: Введен неверный номер месяца \n");
            // В данной ветви break не нужен, т.к. это конец switch
    }
    
    // Вывод результата только если не было ошибки ввода
    if (days != -1) {
        printf("\n В %d месяце дней: %d \n", m, days);
    }
    
    // return 0; // Возвращаем 0, так как stdlib.h не используется
}
```

### 2.2. Роль Оператора `break`

Оператор `break` критически важен для корректной работы `switch`.

  * **С `break`:** После совпадения метки (`case`) выполняется соответствующий код, и `break` **прерывает** выполнение `switch`, передавая управление следующему за ним оператору программы.
  * **Без `break` (Проваливание):** Если `break` отсутствует, выполнение программы **"проваливается"** на следующую ветвь `case`, и код этой следующей ветви также будет выполнен, независимо от того, совпадает ли ее метка с исходным выражением, до тех пор, пока не будет встречен `break` или конец `switch`.

-----

## 3\. Альтернатива: Множественный Выбор с `if-else if-else`

Хотя оператор `switch` очень эффективен для проверки на **равенство целочисленной константе**, для более сложных условий (например, проверки диапазонов или логических выражений) необходимо использовать структуру **`if-else if-else`**.

| Критерий | `switch` | `if-else if-else` |
| :--- | :--- | :--- |
| **Тип условия** | Только проверка на **равенство** (==) целочисленной константе. | Любое **логическое выражение** (\>, \<, &&, \|\|, функции). |
| **Тип выражения** | **Целочисленный** (int, char, enum). | Любой тип, для которого определено логическое сравнение. |
| **Применение** | Идеально для меню, кодов ошибок, однозначных значений. | Идеально для проверки диапазонов, сложных условий, множества переменных. |

```c
// Пример множественного выбора с if-else if-else
if (score >= 90) {
    printf("Отлично");
} else if (score >= 70) {
    printf("Хорошо");
} else if (score >= 50) {
    printf("Удовлетворительно");
} else {
    printf("Неудовлетворительно");
}
```

## 🔄 Лекция 4: Циклы и Цикл с Параметром (`for`)

Эта лекция посвящена **циклическим структурам** в языке Си, которые позволяют многократно выполнять один и тот же блок кода. Особое внимание уделяется циклу **`for`**, или **циклу с параметром**.

-----

## 1\. Концепция Циклических Алгоритмов

### 1.1. Назначение Циклов

**Цикл** — это управляющая конструкция, обеспечивающая многократное выполнение последовательности операторов (тела цикла).

  * **Цель:** Приобретение практических навыков в составлении алгоритмов и программ **циклической структуры** для автоматизации повторяющихся вычислений.

### 1.2. Цикл `for` (Цикл с Параметром)

Цикл **`for`** идеально подходит для случаев, когда **количество повторений** заранее известно или может быть легко вычислено (например, итерация по массиву, выполнение $N$ раз).

#### 📝 Общий Формат

Цикл `for` состоит из **заголовка** и **тела цикла**.

```c
for (начальные_значения; условие_выполнения; действие_в_конце_шага) 
{
    // Тело цикла: операторы, которые выполняются на каждой итерации
}
```

#### ⚙️ Элементы Заголовка

Заголовок содержит три выражения, разделенные точкой с запятой:

| Выражение | Назначение | Выполнение |
| :--- | :--- | :--- |
| **A) Начальные значения (Инициализация)** | Присваивание начальных значений переменным цикла (параметрам). | Выполняется **один раз** перед началом цикла. |
| **B) Условие выполнения (Проверка)** | Логическое выражение, проверяемое перед каждым выполнением тела цикла. | Если условие **истинно** (не равно 0), цикл продолжается. Если **ложно** (равно 0) с самого начала, цикл не выполнится **ни разу** (цикл с **предусловием**). |
| **C) Действие в конце шага (Обновление)** | Операторы, изменяющие параметр цикла (например, инкремент/декремент). | Выполняется **после** каждой итерации тела цикла, но **перед** проверкой условия. |

### 1.3. Синтаксические Особенности `for`

  * **Множественные выражения:** В каждой из трех частей заголовка может быть **несколько операторов**, разделенных **запятыми** (оператор "запятая").
    > **Пример:** `for (i = 0, x = 1.0; i < 10; i += 2, x *= 0.1)`
  * **Тело цикла:**
      * Если тело цикла состоит из **одного оператора**, фигурные скобки `{}` можно опустить.
      * Если тело цикла содержит **несколько операторов**, оно должно быть заключено в фигурные скобки.
  * **Вложенные циклы:** В тело цикла могут входить любые другие операторы, включая другие циклы. Это называется **вложенными циклами** и используется, например, для обработки двумерных массивов.
  * **Стиль:** Для повышения читабельности кода рекомендуется использовать стиль "лесенки" — сдвигать тело цикла вправо на 2-4 пробела (или символ табуляции).

-----

## 2\. Пример Вычисления Суммы

### 2.1. Задача

Вычислить сумму квадратов натуральных чисел от 1 до $n$:
$$S = 1^2 + 2^2 + \dots + n^2$$

### 2.2. Код Программы

```c
#include <stdio.h> // Для printf/scanf
// #include <stdlib.h> // system("CLS") и system("PAUSE")

int main()
{
    // Объявление переменных: S (сумма), n (предел), i (параметр цикла)
    int S, n, i;
    
    // printf("Введите n ");
    if (scanf("%d", &n) != 1 || n < 1) { // Улучшенная проверка ввода
        // fprintf(stderr, "Ошибка ввода или n < 1\n");
        return 1; // Возвращаем код ошибки
    }

    // Заголовок цикла:
    // Инициализация: S=0, i=1 (i - счетчик, S - накопитель)
    // Условие: i<=n (пока счетчик не превысит предел)
    // Обновление: i++ (увеличение счетчика на 1)
    for (S = 0, i = 1; i <= n; i++) 
    {
        S += i * i; // Эквивалентно S = S + i * i;
    }
    
    printf("n=%d S=%d\n", n, S);
    
    // system("PAUSE");
    return 0; // Успешное завершение
}
```

### 2.3. Пояснения к Коду

  * **Инициализация:** `S = 0` — переменная, накапливающая сумму, обнуляется; `i = 1` — счетчик цикла начинается с первого натурального числа.
  * **Условие:** Цикл будет повторяться, пока `i <= n`. Как только `i` станет больше `n`, выполнение цикла прекращается.
  * **Инкремент:** `i++` (постфиксный инкремент) увеличивает счетчик `i` на единицу (`i = i + 1`) после каждой итерации.
  * **Тело цикла:** `S += i * i;` — к текущей сумме `S` прибавляется квадрат текущего числа `i`.

-----

## 3\. Операторы Управления Циклом

Внутри тела цикла могут использоваться специальные операторы для изменения стандартного порядка выполнения итераций.

### 3.1. Оператор `break` (Досрочный Выход)

Оператор **`break`** используется для **немедленного выхода из самого внутреннего цикла** (или `switch`, как было в Лекции 3), независимо от того, выполнено условие цикла или нет.

  * **Назначение:** Применяется, когда в процессе выполнения цикла обнаружено условие, делающее дальнейшие итерации бессмысленными или нежелательными.

<!-- end list -->

```c
for (int i = 0; i < 100; i++) {
    if (значение == 42) {
        printf("Значение найдено!\n");
        break; // Немедленный выход из цикла for
    }
}
// Программа продолжает выполнение отсюда
```

### 3.2. Оператор `continue` (Пропуск Итерации)

Оператор **`continue`** завершает **текущую итерацию** цикла и немедленно переходит к следующей итерации. В цикле `for` это означает, что управление передается к выражению **обновления** (часть C заголовка), а затем проверяется **условие** (часть B).

  * **Назначение:** Применяется, чтобы пропустить часть тела цикла для текущих данных, но продолжить выполнение цикла для следующих данных.

<!-- end list -->

```c
for (int i = 1; i <= 10; i++) {
    if (i % 2 != 0) {
        continue; // Пропускаем нечетные числа
    }
    printf("%d ", i); // Выводятся только четные числа
}
// Результат: 2 4 6 8 10
```

## 🔁 Лекция 5: Циклы с Неизвестным Числом Повторений (`while` и `do-while`)

Эта лекция посвящена циклическим конструкциям **`while`** и **`do-while`**, которые используются, когда **количество повторений цикла заранее неизвестно** и зависит от выполнения определенного условия.

-----

## 1\. Цикл `while` (Цикл с Предусловием)

### 1.1. Назначение и Структура

Цикл **`while`** (пока) выполняет свой блок кода **до тех пор**, пока заданное условие остается истинным.

  * **Применение:** Используется, когда количество итераций неизвестно или зависит от внешних факторов (ввода пользователя, чтения файла, выполнения вычислений).
  * **Цикл с Предусловием:** Условие проверяется **перед** выполнением тела цикла. Если условие ложно в самом начале, цикл **не выполнится ни разу**.

[Image of a flowchart for a 'while' loop showing the condition check occurring before the loop body]

#### 📝 Общий Формат

```c
while (условие) 
{
    // Тело цикла: операторы, которые выполняются
    // Изменение переменных, влияющих на условие
}
```

### 1.2. Особенности Условия в Си

В языке Си логические значения представлены числами:

  * **Истина (True):** Любое число, **не равное нулю**.
  * **Ложь (False):** Число **ноль (0)**.

В условии могут использоваться любые операторы отношения и логические операторы, включая:

  * Сравнение: `==` (равно), `!=` (не равно)
  * Отношение: `>`, `<`, `>=`, `<=`

#### ⚠️ Бесконечный Цикл

Если условие никогда не становится ложным (например, `while (1)`), возникает **бесконечный цикл** (**зацикливание**). Это является серьезной логической ошибкой, если не предусмотрен явный выход (например, с помощью оператора `break`).

  * **Примеры:**
      * `while (1)`: **Бесконечный цикл** (условие всегда истинно).
      * `while (0)`: Цикл **не выполнится ни разу** (условие всегда ложно).

-----

## 2\. Цикл `do-while` (Цикл с Постусловием)

### 2.1. Назначение и Структура

Цикл **`do-while`** (выполнить-пока) выполняет свой блок кода, а затем проверяет условие.

  * **Применение:** Используется, когда необходимо **гарантировать выполнение** тела цикла **хотя бы один раз**, независимо от начального состояния условия.
  * **Цикл с Постусловием:** Условие проверяется **в конце** каждой итерации.

[Image of a flowchart for a 'do-while' loop showing the loop body executing before the condition check]

#### 📝 Общий Формат

```c
do 
{
    // Тело цикла: операторы, которые выполняются
    // Изменение переменных, влияющих на условие
} 
while (условие); // Обратите внимание на точку с запятой!
```

**Важно:** После условия `while` в цикле `do-while` обязательно ставится **точка с запятой** (`;`).

-----

## 3\. Сравнительный Пример: Сумма Ряда (S) до Предела (K)

Рассмотрим задачу: определить наименьшее число $n$, при котором **сумма квадратов натурального ряда** ($S = 1^2 + 2^2 + \dots + n^2$) **превысит** заданную величину $K$, введенную с клавиатуры.

В этом случае число итераций $n$ заранее неизвестно, поэтому используются циклы `while` или `do-while`.

### 3.1. Реализация с Циклом `while` (Предусловие)

В этом варианте цикл выполняется, **пока** текущая сумма $S$ **меньше $K$**.

```c
// Цикл с предусловием (while)
#include <stdio.h>
// #include <stdlib.h> // Для system("CLS")

int main()
{
    int k, s, i;
    
    // printf ("Введите k ");
    scanf ("%d", &k);

    s = 0; // Накопитель суммы
    i = 0; // Счетчик n (текущее число ряда)

    // Условие проверяется перед входом: если s < k, входим в цикл
    while (s < k) 
    { 
        i++;      // Сначала увеличиваем счетчик (n = i + 1)
        s += i * i; // Затем добавляем квадрат i к сумме (S = S + i^2)
    }
    
    printf ("n=%d s=%d\n", i, s);
    return 0;
}
```

### 3.2. Реализация с Циклом `do-while` (Постусловие)

В этом варианте тело цикла выполняется, затем проверяется условие, что $S < K$.

```c
// Цикл с постусловием (do-while)
#include <stdio.h>
// #include <stdlib.h>

int main()
{
    int k, s, i;
    
    // printf ("Введите k ");
    scanf ("%d", &k);

    s = 0; // Накопитель суммы
    i = 0; // Счетчик n

    // Гарантированное выполнение тела цикла 1 раз, затем проверка условия
    do 
    { 
        i++;      // Сначала увеличиваем счетчик
        s += i * i; // Затем добавляем квадрат i к сумме
    }
    while (s < k); // Условие проверяется в конце итерации
    
    printf ("n=%d s=%d\n", i, s);
    return 0;
}
```

### 3.3. Различие между `while` и `do-while`

Ключевое отличие проявляется, когда **условие ложно с самого начала** (например, если ввести $K \le 0$):

| Характеристика | Цикл `while` (Предусловие) | Цикл `do-while` (Постусловие) |
| :--- | :--- | :--- |
| **Проверка условия** | В начале | В конце |
| **$K \le 0$ (Условие $S < K$ ложно)** | **$S=0$, $i=0$** (Цикл не выполняется ни разу) | **$S=1$, $i=1$** (Цикл выполняется 1 раз, затем прерывается) |
| **Выполнение** | Может выполниться **0 или более** раз. | Всегда выполнится **1 или более** раз. |

## 💾 Лекция 6: Тип Данных Массив. Одномерные Массивы

Эта лекция посвящена **массивам** — структурированному типу данных, который позволяет эффективно хранить и обрабатывать набор однотипных элементов под одним общим именем. Мы сосредоточимся на **одномерных массивах**.

-----

## 1\. Понятие Массива

### 1.1. Определение и Характеристики

**Массив** — это структурированный тип данных, представляющий собой последовательный набор элементов **одного и того же типа**, объединенных под **одним именем**.

  * **Однородность:** Все элементы массива должны иметь одинаковый **тип данных** (`int`, `float`, `char` и т.д.).
  * **Имя:** К массиву в целом обращаются по его имени.
  * **Размер:** **Количество элементов** определяет **размер** (длину) массива.
  * **Индекс:** Порядковый номер элемента массива, используемый для доступа к нему.
  * **Размерность:** Число индексов, необходимых для доступа к элементу. Массив с одним индексом называется **одномерным** (вектор), с двумя — **двумерным** (матрица).

### 1.2. Объявление Одномерного Массива

Перед использованием массив необходимо объявить (выделить память).

  * **Формат:** Сначала указывается **тип данных** элементов, затем **имя массива**, а после него в **квадратных скобках** `[]` — **размер** (количество элементов).

<!-- end list -->

```c
int A[10], B[20]; // Объявление двух массивов целых чисел
float C[12];    // Массив из 12 вещественных чисел
char name[50];  // Массив из 50 символов (строка)
```

#### 💡 Использование Констант для Размера

Для повышения универсальности и удобства сопровождения программы, размер массива рекомендуется определять через **константу**. При изменении размера достаточно изменить значение константы.

```c
const int N = 20; // Определение константы
// ...
int main() {
    int A[N]; // Размер массива задан через константу
    // ...
}
```

-----

## 2\. Инициализация и Доступ к Элементам

### 2.1. Инициализация при Объявлении

Массив можно инициализировать (заполнить начальными значениями) сразу при его объявлении, перечисляя значения в **фигурных скобках** `{}`.

  * **Полная инициализация:**
    ```c
    int A[4] = { 2, 3, 12, 76 }; // A[0]=2, A[1]=3, A[2]=12, A[3]=76
    ```
  * **Частичная инициализация:** Если указано меньше значений, чем размер массива, **оставшиеся элементы автоматически заполняются нулями**.
    ```c
    int A[4] = { 2 }; // A[0]=2, A[1]=0, A[2]=0, A[3]=0
    ```
  * **Инициализация без размера:** Если все элементы инициализированы, размер можно опустить — компилятор определит его автоматически.
    ```c
    int B[] = { 1, 2, 3, 4, 5 }; // Размер B будет 5
    ```

### 2.2. Обращение к Элементу Массива

Для обращения к конкретному элементу массива используется его **индекс**.

  * **Правило нумерации (Важно\!):** Элементы массивов в языке Си нумеруются **с нуля (0)**.
      * Если массив имеет размер $N$, его элементы будут иметь индексы от **$0$** до **$N-1$**.
      * Пример: массив `A[10]` содержит элементы `A[0], A[1], ..., A[9]`.

<!-- end list -->

```c
x = (A[3] + 5) * A[1]; // Чтение значений A[3] и A[1]
A[0] = x + 6;          // Запись нового значения в A[0]
A[i] = A[i] * 2;       // Индекс i может быть переменной
```

#### ⚠️ Проблема Выхода за Границы

В языке Си **не контролируется выход за границы массива** (например, обращение к `A[10]` или `A[-1]`, если размер массива равен 10).

  * **Последствия:** Такое обращение приводит к чтению или записи данных в области памяти, не принадлежащие массиву. Это может привести к **непредсказуемому поведению программы**, повреждению данных других переменных или функций, и часто вызывает **аварийное завершение** программы.

-----

## 3\. Обработка Массивов

Обработка массивов всегда включает итерацию по их элементам, для чего идеально подходит цикл **`for`**.

### 3.1. Ввод и Вывод Массива

Чтобы обработать (ввести или вывести) массив, необходимо обработать **каждый его элемент отдельно** в цикле.

  * **Ввод (с клавиатуры):** Для каждого элемента `A[i]` вызывается функция `scanf()`, при этом не забываем использовать оператор **взятия адреса `&`** перед элементом массива (кроме случаев, когда элемент сам является массивом, например, строка).

<!-- end list -->

```c
// Ввод массива 'a' размера 'n'
for (i = 0; i < n; i++) {
    printf("Введите элемент a[%d]: ", i);
    scanf("%d", &a[i]); // Используем &
};

// Вывод массива 'a'
for (i = 0; i < n; i++) {
    printf("%6d", a[i]); // Вывод с форматированием
}
```

### 3.2. Пример: Нахождение Максимального Элемента и Его Индекса

**Задача:** Найти наибольший элемент в массиве $a[N]$ и его порядковый номер (индекс).

```c
// ...
const int N = 10;
int main() {
    int i, max, nom, a[N]; 
    
    // ... ввод массива ...
    
    // 1. Инициализация (Предполагаем, что первый элемент — максимум)
    max = a[0]; // Максимальное значение
    nom = 0;    // Индекс максимального элемента
    
    // 2. Поиск максимума: начинаем со второго элемента (i=1)
    for (i = 1; i < N; i++) {
        if (a[i] > max) { // Используем > для строгого поиска
            max = a[i];  // Обновляем значение максимума
            nom = i;     // Обновляем индекс
        } 
    }
    
    // Вывод результата: nom + 1, чтобы получить порядковый номер, начинающийся с 1.
    printf("\n Максимальное число в массиве %4d, его порядковый номер %4d", max, nom + 1);
    // ...
}
```

### 3.3. Заполнение Случайными Числами

Для моделирования или тестирования часто требуется заполнить массив случайными числами. Для этого используются функции из заголовочного файла **`<stdlib.h>`**: `rand()` и `srand()` (для инициализации генератора).

#### 🎲 Генерация Целых Чисел в Диапазоне $[a, b]$

Используется функция `rand()` и оператор взятия остатка по модулю (`%`).

  * Функция `rand() % N` выдает случайное число в диапазоне $[0, N-1]$.
  * Для получения диапазона $[a, b]$ используется формула:
    $$\text{случайное число} = \text{rand()} \pmod{(b - a + 1)} + a$$

<!-- end list -->

```c
// Пример для целых чисел в интервале [-5, 10]
int a = -5, b = 10;
// Для получения диапазона [a, b], где b - a + 1 = 16
A[i] = rand() % (b - a + 1) + a; 
```

#### 🔬 Генерация Вещественных Чисел в Диапазоне $[a, b]$

Используется константа **`RAND_MAX`** (максимальное случайное число, которое может выдать `rand`).

$$\text{случайное число} = \frac{\text{rand()}}{\text{RAND\_MAX}} \times (b - a) + a$$

```c
// Пример для вещественных чисел в интервале [-5.0, 10.0]
float a = -5.0, b = 10.0;
X[i] = (float)rand() * (b - a) / RAND_MAX + a;
```

## 🔍 Лекция 7: Обработка Одномерных Массивов

Эта лекция посвящена **типовым алгоритмам** обработки одномерных массивов, включая линейный поиск различных видов и простейший метод сортировки.

-----

## 1\. Типовые Алгоритмы Обработки Массивов

### 1.1. Линейный Поиск

**Линейный поиск** (или **последовательный поиск**) — это простейший алгоритм, при котором элементы массива **последовательно перебираются** один за другим от начального (индекс 0) до конечного (индекс $N-1$). Для его реализации всегда используется цикл `for`.

Основные задачи поиска:

1.  Поиск одного заданного элемента.
2.  Поиск всех элементов, удовлетворяющих условию (с подсчетом или без).
3.  Поиск минимального или максимального элемента.

#### 🔎 Поиск Одного Элемента (С использованием Флага)

**Задача:** Определить, присутствует ли в массиве элемент с заданным значением $X$, и найти его индекс.

Для решения этой задачи используется переменная-**флаг** (flag):

  * **Флаг (Flag):** Специальная переменная, которая сигнализирует о наступлении определенного события.
      * **Сброшен (0/False):** Событие еще не произошло (элемент не найден).
      * **Установлен (1/True):** Событие произошло (элемент найден).

<!-- end list -->

```c
// ...
int i, X, A[N];
int flag = 0; // Флаг сброшен (0)

// ... Ввод массива и искомого числа X ...

for (i = 0; i < N; i++)
    if (A[i] == X) 
    {
        flag = 1; // Поднимаем флаг
        break;    // Немедленно заканчиваем поиск (оптимизация)
    }

if (flag)
    // Если флаг установлен, i содержит индекс найденного элемента
    printf("A[%d] = %d", i, A[i]); 
else
    printf("Число %d не найдено", X);
// ...
```

> **Преимущество `break`:** Как только элемент найден, оператор `break` **досрочно завершает** цикл, что экономит вычислительное время, поскольку дальнейший просмотр массива становится ненужным.

#### 🔢 Поиск Всех Элементов (С использованием Счетчика)

**Задача:** Определить, сколько в массиве положительных элементов, и вывести их на экран.

Для решения этой задачи используется переменная-**счетчик** (count):

  * **Счетчик (Counter):** Специальная переменная, которая увеличивается на единицу при каждом выполнении условия.

<!-- end list -->

```c
// ...
int i, A[N], count = 0; // count – счетчик положительных элементов

// ... Ввод или генерация массива ...

for (i = 0; i < N; i++) // Цикл по всем элементам массива
    if (A[i] > 0) 
    { 
        count++; // Увеличиваем счетчик
        printf("%d  ", A[i]); // Выводим элемент
    }
    
printf("\n В массиве %d положительных чисел", count);
// ...
```

#### ⚖️ Поиск Максимального (Минимального) Элемента

Этот алгоритм был рассмотрен в предыдущей лекции и является частным случаем поиска:

1.  Инициализируем переменную `max` первым элементом массива (`A[0]`).
2.  Проходим циклом по массиву, начиная со второго элемента (`i=1`).
3.  Если текущий элемент `A[i]` больше `max`, обновляем `max` и сохраняем текущий индекс `i`.

-----

## 2\. Сортировка Массивов

**Сортировка** — это процесс расстановки элементов в заданном порядке (например, по возрастанию или убыванию). Сортировка является одной из наиболее фундаментальных задач в программировании.

Алгоритмы сортировки делятся на:

  * **Простые, но неэффективные** (например, "пузырек", выбором, вставками).
  * **Сложные, но эффективные** (например, быстрая сортировка, слиянием).

### 2.1. Метод Пузырька (Bubble Sort)

**Метод пузырька** — это простой, но медленный алгоритм. Он получил название из-за того, что "легкие" (минимальные) элементы "всплывают" к началу массива при каждом проходе.

#### 📝 Принцип работы

1.  Алгоритм использует **два вложенных цикла**.
2.  **Внешний цикл** (например, по `i`) контролирует количество полных проходов. Для массива размером $N$ достаточно $N-1$ проходов.
3.  **Внутренний цикл** (например, по `j`) сравнивает соседние элементы.
4.  Если соседние элементы стоят в неправильном порядке (например, $A[j] > A[j+1]$ для сортировки по возрастанию), они **меняются местами** (происходит **обмен**).
5.  После первого прохода самый большой элемент гарантированно оказывается в конце массива. На каждом следующем проходе область сравнения уменьшается.

#### 💻 Реализация "Пузырька" (Сортировка по возрастанию)

```c
// ...
    int i, j, A[N], c; // c – временная переменная для обмена
    
    // ... Генерация исходного массива A ...

    // 1. Внешний цикл: N-1 проходов
    for (i = 0; i < N - 1; i++) 
    { 
        // 2. Внутренний цикл: сравнение соседних элементов. 
        // j=N-2, т.к. сравниваем A[j] с A[j+1].
        // Идем с конца в начало до индекса i (потому что элементы до i уже отсортированы)
        for (j = N - 2; j >= i; j--) 
        {
            if (A[j] > A[j + 1]) // Если элементы стоят неправильно (нужна перестановка)
            {
                // Процесс обмена значений (требуется третья временная переменная 'c')
                c = A[j]; 
                A[j] = A[j + 1]; 
                A[j + 1] = c;
            }
        }
    }
    
    // ... Вывод отсортированного массива ...
// ...
```

-----

## 3\. Операция Обмена Значениями

Обмен значениями двух переменных (`A[j]` и `A[j+1]`) — это базовый прием, часто используемый в сортировке.

### 3.1. Алгоритм Обмена

Для корректного обмена всегда требуется **временная (буферная) переменная** (`c` в примере выше):

1.  Сохранить значение первой переменной во временной: `c = A[j];`
2.  Присвоить первой переменной значение второй: `A[j] = A[j+1];`
3.  Присвоить второй переменной сохраненное временное значение: `A[j+1] = c;`

-----

## 🔢 Лекция 8: Численные Методы и Применение Массивов (Вычисление Интегралов)

## 1\. Цель работы

Приобретение навыков программирования **численных методов интегрирования** (методы трапеций и Симпсона) для вычисления определенных интегралов, используя массивы для хранения данных.

-----

## 2\. Основные Сведения: Численное Интегрирование

### 2.1. Понятие Определенного Интеграла

**Определенный интеграл** $\int_a^b f(x) \, dx$ геометрически представляет собой **площадь** под кривой функции $f(x)$, ограниченную на интервале $[a, b]$.

**Численное интегрирование** — это приближенное вычисление этой площади путем разбиения интервала $[a, b]$ на $N$ маленьких отрезков и замены сложной функции $f(x)$ на этих отрезках на более простую (интерполирующую) функцию.

### 2.2. Подготовка Данных (Массив значений)

Для численного интегрирования интервал интегрирования $[a, b]$ разбивается на $N$ равных частей, создавая $N+1$ точку: $x_0, x_1, \dots, x_N$.

  * **Шаг интегрирования $h$:**
    $$h = \frac{b - a}{N}$$
  * **Точки:** $x_i = a + i \cdot h$, где $i = 0, 1, \dots, N$.
  * **Массив $Y$:** Значения заданной функции $f(x)$ в этих точках сохраняются в одномерном массиве $Y$:
    $$Y = \{y_0, y_1, y_2, \dots, y_N\}$$
    где $y_i = f(x_i)$.

### 2.3. Метод Трапеций (Кусочно-линейная интерполяция)

Метод трапеций приближает площадь под кривой, заменяя функцию $f(x)$ на каждом маленьком отрезке $[x_i, x_{i+1}]$ прямой линией. Полученные фигуры являются **трапециями**.

**Формула трапеций:**
$$\int_a^b f(x) \, dx \approx h \left[ \frac{y_0 + y_N}{2} + \sum_{i=1}^{N-1} y_i \right]$$

**Алгоритм:**

1.  Вычислить **сумму внутренних элементов** массива $Y$ (от $y_1$ до $y_{N-1}$).
2.  Добавить **половину** крайних элементов ($y_0 / 2 + y_N / 2$).
3.  Умножить полученную сумму на шаг $h$.

### 2.4. Метод Симпсона (Кусочно-квадратичная интерполяция)

Метод Симпсона (или метод парабол) является более точным, поскольку он аппроксимирует функцию на каждом двойном отрезке параболой (квадратичной функцией). Требуется, чтобы количество отрезков $N$ было **четным**.

**Формула Симпсона:**
$$\int_a^b f(x) \, dx \approx \frac{h}{3} \left[ y_0 + y_N + 4 \sum_{\text{нечетные } i} y_i + 2 \sum_{\text{четные } j} y_j \right]$$
где $i = 1, 3, 5, \dots, N-1$ и $j = 2, 4, 6, \dots, N-2$.

**Алгоритм:**

1.  Вычислить **сумму нечетных элементов** ($S_{odd} = y_1 + y_3 + \dots$).
2.  Вычислить **сумму четных элементов** ($S_{even} = y_2 + y_4 + \dots$).
3.  Итоговая сумма: $\text{Result} = y_0 + y_N + 4 \cdot S_{odd} + 2 \cdot S_{even}$.
4.  Умножить результат на $h / 3$.

-----

## 3\. Требования к Программной Реализации

Для решения этой задачи требуется объединить навыки работы с циклами и массивами:

  * **Объявление:** Объявить массив `float Y[N+1]` для хранения значений.
  * **Заполнение:** Использовать цикл `for` для вычисления $x_i$ и заполнения массива $Y$ значениями $f(x_i)$.
  * **Вычисление:** Использовать цикл(ы) `for` для прохода по массиву $Y$ и выполнения суммирования согласно формулам.

> **Пример цикла для Симпсона (суммирование):**
>
> ```c
> float sum_odd = 0.0, sum_even = 0.0;
> for (i = 1; i < N; i++) {
>     if (i % 2 != 0) { // Нечетный индекс
>         sum_odd += Y[i];
>     } else { // Четный индекс
>         sum_even += Y[i];
>     }
> }
> // ... далее применить формулу Симпсона
> ```

## 📐 Лекция 9: Двумерные Массивы (Матрицы)

Эта лекция посвящена **двумерным массивам**, известным как **матрицы**, и основным алгоритмам их обработки в языке Си.

-----

## 1\. Концепция Матриц

### 1.1. Определение и Представление

**Матрица** — это прямоугольная таблица элементов (чисел, символов и т.д.), которая в языке Си представляется **двумерным массивом**.

  * **Два Индекса:** Каждый элемент матрицы имеет два индекса:
    1.  **Первый индекс (i):** Номер **строки**.
    2.  **Второй индекс (j):** Номер **столбца**.
  * **Иерархия:** Матрицу можно рассматривать как **массив, элементами которого являются одномерные массивы** (строки).
  * **Размерность:** Матрица "M на N" имеет **M строк** и **N столбцов**.
  * **Квадратная Матрица:** Матрица, у которой число строк равно числу столбцов ($M = N$).

### 1.2. Объявление Матриц

Матрицы объявляются аналогично одномерным массивам, но с двумя парами квадратных скобок, в которых указываются размеры строк и столбцов.

  * **Формат:** `тип имя_массива[количество_строк][количество_столбцов];`

<!-- end list -->

```c
// Выделит место под матрицу целых чисел: 10 строк, 10 столбцов
int B[10][10]; 

// Использование констант для универсальности
const int M = 5; // число строк
const int N = 4; // число столбцов
int A[M][N];
```

  * **Инициализация:**
      * **Глобальные матрицы** (объявленные вне функций) по умолчанию заполняются **нулями**.
      * **Локальные матрицы** (объявленные внутри функций) изначально содержат **неизвестные значения** ("мусор").

### 1.3. Начальные Значения и Расположение в Памяти

При инициализации начальные значения элементов каждой строки заключаются в **отдельные фигурные скобки**.

```c
// Матрица 2 строки на 3 столбца
float X[2][3] = {{1.0, 2.0, 3.0}, // Первая строка: X[0][0], X[0][1], X[0][2]
                 {4.0, 5.0, 6.0}}; // Вторая строка: X[1][0], X[1][1], X[1][2]
```

  * **Частичная Инициализация:** Если задано меньше элементов, оставшиеся заполняются **нулями**.
    ```c
    float Y[2][3] = {{1.0, 3.0}, {6.0}};
    // Y[0][0]=1.0, Y[0][1]=3.0, Y[0][2]=0.0
    // Y[1][0]=6.0, Y[1][1]=0.0, Y[1][2]=0.0
    ```
  * **Расположение в Памяти:** В Си элементы двумерного массива хранятся **построчно** (т.е. сначала идет вся первая строка, затем вся вторая и т.д.). При обращении к элементам сначала изменяется **последний индекс (столбец)**.

-----

## 2\. Работа с Матрицами (Вложенные Циклы)

Для обработки каждого элемента матрицы (ввод, вывод, вычисление) необходимо использовать **двойной (вложенный) цикл**.

  * **Внешний цикл:** Проходит по **строкам** (индекс $i$).
  * **Внутренний цикл:** Проходит по **столбцам** (индекс $j$) внутри текущей строки.

### 2.1. Ввод и Инициализация

#### Стандартный Ввод

```c
// ... const int M = 5, N = 4; int A[M][N];
for (i = 0; i < M; i++) // Цикл по строкам
{ 
    for (j = 0; j < N; j++) // Цикл по столбцам
    {
        printf("A[%d][%d]=", i, j); 
        scanf("%d", &A[i][j]); 
    }
}
```

#### Заполнение Случайными Числами

Генерация случайных чисел в интервале $[a, b]$ также требует двойного цикла.
$$\text{A[i][j]} = \text{rand()} \pmod{(b - a + 1)} + a$$

```c
// Генерация целых чисел в интервале [a, b]
for (i = 0; i < M; i++)
    for (j = 0; j < N; j++)
        A[i][j] = random(b - a + 1) + a; // Предполагается, что random(R) = rand() % R
```

### 2.2. Вывод Матрицы на Экран

Для корректного табличного вывода необходимо:

1.  Использовать **вложенный цикл**.
2.  Использовать **форматирование** (`%4d` или `%6.2f`), чтобы отвести равное количество символов на каждый элемент.
3.  После завершения **внутреннего цикла** (вывода строки) обязательно выполнить **перевод строки** (`printf("\n")`).

<!-- end list -->

```c
printf("Матрица A\n");
for (i = 0; i < M; i++) // Цикл по строкам
{ 
    for (j = 0; j < N; j++) // Вывод одной строки
    {
        printf("%4d", A[i][j]); // 4 символа на число
    }
    printf("\n"); // Переход на новую строку после каждой строки матрицы
}
```

-----

## 3\. Типовые Алгоритмы Обработки Матриц

### 3.1. Поиск Минимального/Максимального Элемента

Алгоритм аналогичен одномерному массиву, но используется двойной цикл. Необходимо запоминать не только само значение, но и его **индексы** (`row` и `col`).

```c
// ... int A[M][N]; int min_val, row = 0, col = 0;
min_val = A[0][0]; // Начальное предположение
row = 0; col = 0;  // Сохраняем индексы минимального

for (i = 0; i < M; i++) // Просмотр всех строк
    for (j = 0; j < N; j++) // Просмотр всех столбцов
        if (A[i][j] < min_val) // Если найден меньший элемент
        {
            min_val = A[i][j]; // Запоминаем новое значение
            row = i;           // Запоминаем индекс строки
            col = j;           // Запоминаем индекс столбца
        }
        
printf("Минимальный элемент A[%d][%d]=%d", row, col, min_val);
```

### 3.2. Работа с Диагоналями (Для Квадратных Матриц $N \times N$)

#### 1\. Главная Диагональ

Элементы, у которых **индекс строки равен индексу столбца** ($i = j$).

```c
// Вывод главной диагонали
for (i = 0; i < N; i++) {
    printf("%4d", A[i][i]); // A[0][0], A[1][1], ..., A[N-1][N-1]
}
```

#### 2\. Побочная (Вторая) Диагональ

Элементы, у которых **сумма индексов строки и столбца постоянна** и равна $N-1$ ($i + j = N - 1$).
Следовательно, элемент в строке $i$ находится в столбце $j = N - 1 - i$.

```c
// Вывод побочной диагонали
for (i = 0; i < N; i++) {
    printf("%4d", A[i][N - 1 - i]); // A[0][N-1], A[1][N-2], ..., A[N-1][0]
}
```

### 3.3. Перестановка Строк

Перестановка двух строк (с индексами $i_1$ и $i_2$) требует обмена элементами **в каждом столбце** $j$ с использованием временной переменной.

```c
int temp;
int i1 = 1; // Индекс первой строки
int i2 = 3; // Индекс второй строки

for (j = 0; j < N; j++) // Цикл по столбцам
{
    temp = A[i1][j];    // Сохранить элемент первой строки
    A[i1][j] = A[i2][j]; // Присвоить первой строке элемент второй
    A[i2][j] = temp;    // Присвоить второй строке сохраненный элемент
}
// Перестановка столбцов выполняется аналогично, но цикл идет по строкам (i)
```

### 3.4. Пример: Поэлементные Операции над Двумя Матрицами

**Задача:** Даны две матрицы $A$ и $B$ одинакового размера $M \times N$. Получить матрицу $C$, где $C[i][j] = \max(A[i][j], B[i][j])$, и матрицу $D$, где $D[i][j] = \min(A[i][j], B[i][j])$.

```c
// ... Объявление A[m][n], B[m][n], C[m][n], D[m][n]
// ... Заполнение A и B случайными числами
// ... Вывод A и B

// Формирование матриц C и D
for (i = 0; i < m; i++)
    for (j = 0; j < n; j++)
    {
        if (a[i][j] > b[i][j]) // Сравнение соответствующих элементов
        {
            c[i][j] = a[i][j]; // C - максимум
            d[i][j] = b[i][j]; // D - минимум
        }
        else
        {
            c[i][j] = b[i][j];
            d[i][j] = a[i][j];
        }
    }
// ... Вывод C и D
```

## 📜 Лекция 10: Работа с Символьными Данными и Строками

Эта лекция посвящена типу данных **`char`** (символы) и **строкам** — массивам символов, завершающимся специальным нуль-символом (`\0`), а также основным функциям для их обработки в языке Си.

-----

## 1\. Символы и Символьные Строки

### 1.1. Понятие Символа (`char`)

  * **Символьная константа** — это одиночный символ, заключенный в **одинарные кавычки** (апострофы), например, `'X'`, `'3'`, `'\n'`.
  * **Код символа (ASCII):** Значением символьной константы является ее **численное представление** (код) в принятой кодировке (например, ASCII).
      * Пример: код символа `'A'` равен 65, код символа `'3'` равен 51.
  * **Операции:** Символы могут сравниваться по своим кодам (например, `'A' < 'B'` истинно, так как $65 < 66$). Арифметические операции для символов не определены.

### 1.2. Представление Строки в Си

  * **Символьная строка** — это последовательность символов.
  * **Правило Си:** Строка — это **массив символов**, который **обязательно** должен заканчиваться **нулевым символом** (признаком окончания строки, **терминатором**).
      * **Нуль-символ:** Символ с кодом 0, записывается как `'\0'`. Он не имеет графического изображения.

-----

## 2\. Объявление и Инициализация Строк

### 2.1. Объявление

Строка объявляется как одномерный массив символов (`char`).

```c
char str[80]; // Массив на 80 символов. Фактическая строка будет иметь макс. длину 79 символов + '\0'.
```

> **Важно:** Всегда выделяйте на **1 байт больше** памяти, чем максимальное количество символов, которое должна содержать строка, чтобы вместить завершающий `'\0'`.

### 2.2. Инициализация (Строковый Литерал)

Начальное значение строки можно задать при объявлении, используя **двойные кавычки**. В этом случае компилятор **автоматически** добавляет завершающий `'\0'`.

```c
// '\0' добавляется автоматически
char str[80] = "Привет, ИП-10!"; 

// Компилятор сам подсчитает длину (14 символов + 1 для '\0' = 15 байт)
char str[] = "Привет, ИП-11!"; 

// Константная строка (не может быть изменена)
const char PRIVET[] = "Привет семье!"; 
```

-----

## 3\. Стандартный Ввод и Вывод Строк

### 3.1. Форматный Ввод/Вывод

| Функция | Назначение | Спецификатор | Особенности |
| :--- | :--- | :--- | :--- |
| `printf()` | Вывод строки | `%s` | Позволяет форматировать вывод (например, `%15s` или `%-15s`). |
| `scanf()` | Ввод строки | `%s` | **Останавливает ввод** при первом **пробеле, табуляции или переводе строки**. |
| `getchar()` / `putchar()` | Ввод/вывод одиночного символа | `%c` | Используются для посимвольного ввода/вывода. |

> **Обращение к `scanf`:** При вводе строки с помощью `scanf("%s", Name)` используется **только имя массива** (`Name`), поскольку имя массива уже является адресом его начального элемента. Оператор адреса (`&`) не требуется.

### 3.2. Функции для Ввода/Вывода Целиком

Для ввода строки, содержащей пробелы, используются специальные неформатируемые функции:

  * **`gets(str)`:** Вводит всю строку, включая пробелы, до нажатия Enter. (В современном Си **не рекомендуется** использовать `gets()` из-за опасности переполнения буфера. Лучше использовать `fgets()`).
  * **`puts(str)`:** Выводит строку на экран и **автоматически переходит на новую строку**.

### 3.3. Посимвольная Обработка (Цикл `while`)

Для обработки строки (например, замены символов, подсчета цифр) используется цикл, который продолжается до тех пор, пока не встретится символ `'\0'`.

**Пример: Замена 'A' на 'Б'**

```c
// ...
char str[80];
int i = 0;

gets(str);

// Цикл: пока текущий символ не равен терминатору '\0'
while (str[i] != '\0') 
{
    if (str[i] == 'A') // Если очередной символ — 'A'
    {
        str[i] = 'Б'; // Заменяем его на 'Б'
    }
    i++; // Переходим к следующему символу
}
puts("Результат:");
puts(str);
// ...
```

-----

## 4\. Библиотечные Функции Строк (`<string.h>`)

Для работы со строками необходимо подключить заголовочный файл **`<string.h>`**.

| Функция | Назначение | Возвращаемое значение | Примечания |
| :--- | :--- | :--- | :--- |
| **`strlen(str)`** | **Длина строки** | Число символов (тип `size_t`), **не включая** `'\0'`. | Имя: **Str**ing **Len**gth. |
| **`strcpy(s2, s1)`** | **Копирование** | Указатель на `s2`. | Копирует строку `s1` (источник) в строку `s2` (приемник), включая `'\0'`. **Опасно:** Не проверяет размер `s2`. |
| **`strncpy(s2, s1, n)`** | **Копирование N символов** | Указатель на `s2`. | Копирует `n` символов. **НЕ** добавляет `'\0'` автоматически. Требуется ручное добавление: `s2[n] = '\0';`. |
| **`strcat(s1, s2)`** | **Объединение (конкатенация)** | Указатель на `s1`. | Добавляет `s2` в конец `s1`. **Опасно:** Приемник `s1` должен иметь достаточный размер. |
| **`strcmp(s1, s2)`** | **Сравнение** | `0`, если строки равны; `< 0`, если $s1 < s2$; `> 0`, если $s1 > s2$. | Сравнение происходит лексикографически (по кодам символов). |
| **`strncmp(s1, s2, n)`** | **Сравнение N символов** | Аналогично `strcmp`. | Сравнивает только первые `n` символов. |

### 4.1. Функции Поиска в Строках

Функции поиска возвращают **указатель** на найденное место. Если элемент не найден, возвращается `NULL`.

  * **`strchr(s, c)`:** Находит **первое** вхождение символа `c` в строке `s`.
  * **`strrchr(s, c)`:** Находит **последнее** вхождение символа `c` в строке `s`.
  * **`strstr(s1, s2)`:** Находит **первое** вхождение подстроки `s2` в строке `s1`.

**Получение индекса:** Чтобы получить индекс (номер) найденного символа/подстроки, нужно вычесть адрес начала массива (`s`) из полученного указателя (`p`).
$$\text{Индекс} = p - s$$

```c
// ...
char s1[] = "Мама мыла раму", *p;
p = strchr(s1, 'а'); // p указывает на 'а' в "Мама"
if (p != NULL) 
    printf("Первая буква 'а' имеет индекс: %d", p - s1); // Вывод: 1
// ...
```

### 4.2. Поиск Цифр (Пример с Диапазоном Кодов)

Проверка, является ли символ цифрой, часто основывается на том, что коды цифр (`'0'` до `'9'`) расположены в таблице ASCII последовательно.

```c
// ...
// Проверка, является ли s[i] цифрой
if (s[i] >= '0' && s[i] <= '9') 
    count++;
// ...
```

## 🎨 Лекция 11: Работа в Графическом Режиме

Эта лекция знакомит с основами **компьютерной графики** в среде языка Си, используя популярную библиотеку **`graphics.h`** для создания простых рисунков в отдельном окне.

-----

## 1\. Основы Графического Режима

### 1.1. Включение Графики

Для использования графических функций необходимо:

1.  Подключить заголовочный файл **`#include <graphics.h>`**.
2.  Открыть специальное графическое окно с помощью функции **`initwindow`**.

<!-- end list -->

  * **`initwindow(ширина, высота)`:** Открывает дополнительное окно, где `ширина` и `высота` задаются в **пикселях**.
  * **`closegraph()`:** Закрывает графическое окно и освобождает ресурсы (вызывается в конце программы).

### 1.2. Система Координат

В графическом режиме принята следующая система координат:

  * **Начало координат (0, 0):** Находится в **левом верхнем углу** графического окна.
  * **Ось X:** Направлена **вправо**.
  * **Ось Y:** Направлена **вниз** (в отличие от стандартной математической системы, где ось Y направлена вверх).

### 1.3. Пример Простейшей Графической Программы

```c
#include <stdlib.h>
#include <graphics.h>
#include <conio.h> // Для getch()

int main()
{
    // Открыть графическое окно размером 640 на 360 пикселей
    initwindow(640, 360, "Мое Графическое Окно"); 

    setcolor(GREEN); // Установить цвет линий (зеленый)
    
    // Рисование первой линии (ломаной)
    moveto(0, 0);       // Перевести курсор в точку (0, 0)
    lineto(320, 180);   // Нарисовать отрезок до центра (320, 180)
    lineto(640, 0);     // Нарисовать отрезок до правого верхнего угла

    setcolor(YELLOW); // Установить цвет линий (желтый)
    moveto(0, 360);
    lineto(320, 180);
    lineto(640, 360);

    // Рисование окружности
    setcolor(RED); 
    circle(320, 180, 50); // Окружность: центр (320, 180), радиус 50
    
    getch();          // Ожидать нажатия любой клавиши, чтобы окно не закрылось сразу
    closegraph();     // Закрыть графическое окно
    
    return 0;
}
```

## 🎬 Лекция 12: Анимация и Управление Движением

-----

## 1\. Цель работы

Приобретение практических навыков в программировании **движения графических объектов** и реализации интерактивного управления ими в графическом режиме.

-----

## 2\. Основные Сведения

### 2.1. Принципы Компьютерной Анимации

**Анимация** в компьютерной графике — это иллюзия движения, создаваемая последовательной сменой неподвижных изображений (кадров) в одной и той же области экрана.

Основной алгоритм для создания движения:

1.  **Рисование:** Изобразить объект на экране в текущих координатах $(x, y)$.
2.  **Задержка:** Создать небольшую паузу (задержку) с помощью функции **`delay(ms)`** (обычно 10–50 мс), чтобы скорость движения была видна глазу.
3.  **Стирание:** Убрать объект с экрана, перерисовав его цветом фона (или используя специальные графические методы).
4.  **Сдвиг:** Изменить координаты $(x, y)$ объекта (например, $x = x + \Delta x$).
5.  **Повтор:** Переход к шагу 1 (рисование в новых координатах).

### 2.2. Свободное Движение Объекта

**Свободное движение** — это движение объекта по заранее заданному правилу (например, по прямой), которое продолжается до тех пор, пока не будет нарушено условие цикла (например, выход за границу экрана или нажатие клавиши).

Для реализации стирания и рисования удобно использовать вспомогательную функцию, которая принимает координаты и цвета.

#### 💻 Пример: Движение круга до границы или нажатия Esc

```c
#include <conio.h>    // Для kbhit() и getch()
#include <graphics.h> // Для графических функций
#include <stdlib.h>   // Для initwindow

// Функция для рисования/стирания круга
// color1 - цвет контура, color2 - цвет заливки
void Draw(int x, int y, int color1, int color2) 
{
    setcolor(color1);
    setfillstyle(1, color2); // Стиль 1: сплошная заливка
    circle(x, y, 20);        // Рисуем окружность радиусом 20
    floodfill(x, y, color1); // Заливаем цветом color2 до границы color1
}

int main()
{
    int x, y; // Координаты центра окружности
    
    // Инициализация окна 400x400
    initwindow(400, 400, "Свободное Движение"); 
    
    // Заливка фона черным (цвет 0)
    setfillstyle(1, BLACK); 
    bar(0, 0, 399, 399); 
    
    x = 20; y = 200; // Начальные координаты (слева по центру)
    
    /* Анимация */
    // Продолжаем, пока правый край круга (x + радиус 20) не достигнет границы 400
    while (x + 20 < 400) 
    {
        // 1. Проверка на нажатие клавиши
        if (kbhit()) // Возвращает ненулевое значение, если нажата клавиша
        {
            if (getch() == 27) // 27 — код клавиши Esc
                break; // Выход из цикла
        }

        // 2. Рисование (белый контур, красная заливка)
        Draw(x, y, WHITE, RED); 
        
        // 3. Задержка (20 мс)
        delay(20); 
        
        // 4. Стирание (перерисовка черным цветом)
        Draw(x, y, BLACK, BLACK); 
        
        // 5. Сдвиг
        x++; 
    }
    
    closegraph(); 
    return 0;
}
```

#### 📌 Функции для Свободного Движения

| Функция | Назначение |
| :--- | :--- |
| **`delay(ms)`** | Приостанавливает выполнение программы на заданное количество миллисекунд. |
| **`kbhit()`** | Проверяет, была ли нажата клавиша. Не блокирует программу. Возвращает 0, если нет нажатия. |
| **`getch()`** | Читает код нажатой клавиши. **Блокирует** выполнение программы до нажатия. Используется внутри `if (kbhit())` для немедленного чтения, если клавиша была нажата. |

-----

### 2.3. Управление Движением Клавишами-Стрелками

Для реализации **управляемого движения** необходимо, чтобы объект перемещался только после нажатия пользователем соответствующей клавиши.

#### 🕹️ Алгоритм Управления

1.  Запускается **бесконечный цикл** (`while(1)`).
2.  Объект рисуется в текущих координатах $(x, y)$.
3.  Программа **ожидает** нажатия клавиши (`code = getch()`).
4.  Проверяется выход по `Esc` (код **27**).
5.  Объект стирается (перерисовывается цветом фона).
6.  С помощью оператора **`switch`** анализируется код клавиши:
      * Если нажата "стрелка", координаты $x$ или $y$ изменяются на шаг ($\pm \Delta$).
      * Иначе координаты не меняются.
7.  Цикл повторяется.

#### 🔑 Особенности Клавиш-Стрелок

Клавиши управления курсором (стрелки) являются **функциональными** клавишами. В некоторых средах (как, например, в BGI/Turbo C, для которых разработана эта библиотека) они генерируют **два кода** при одном нажатии:

1.  Первый код всегда **0** (или `224`).
2.  Второй код — это **скан-код**, который и указывает на конкретную стрелку.

В упрощенном подходе, представленном ниже (который работает в большинстве эмуляций BGI), используется только второй код (скан-код):

| Клавиша | Скан-код | Изменение |
| :--- | :--- | :--- |
| **Стрелка ВЛЕВО** | **75** | $x = x - \Delta x$ |
| **Стрелка ВПРАВО** | **77** | $x = x + \Delta x$ |
| **Стрелка ВВЕРХ** | **72** | $y = y - \Delta y$ |
| **Стрелка ВНИЗ** | **80** | $y = y + \Delta y$ |

#### 💻 Реализация Управления

```c
// ... функция Draw(...)
// ... инициализация окна и переменных x, y

int code; 
// ... x, y, color1, color2, color_bg (цвет фона)

while (1) // Бесконечный цикл
{
    // 1. Рисуем фигуру в текущих координатах
    Draw(x, y, WHITE, RED); 
    
    // 2. Ждем нажатия клавиши
    code = getch(); 
    
    // 3. Проверяем выход (Esc)
    if (code == 27) 
        break; 

    // 4. Стираем фигуру перед перемещением
    Draw(x, y, BLACK, BLACK); 

    // 5. Анализируем код и меняем координаты
    switch (code) 
    { 
        case 75: x--; break; // Влево (уменьшаем X)
        case 77: x++; break; // Вправо (увеличиваем X)
        case 72: y--; break; // Вверх (уменьшаем Y)
        case 80: y++; break; // Вниз (увеличиваем Y)
    }
    
    // Можно добавить небольшую задержку, хотя getch() уже замедляет
    // delay(1); 
}

// ... closegraph()
```
