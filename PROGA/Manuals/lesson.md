# 💻 1 Лекция: Функции в языке Си

## 🎯 Цель лекции

Изучение и практическое применение **функций** как основного механизма модульности и повторного использования кода в языке программирования Си.

-----

## 💡 Основные сведения о функциях

### Что такое функция?

В программировании функция (или **подпрограмма**) — это автономный, именованный блок кода, который выполняет определённую, логически завершённую задачу (алгоритм).

Главное назначение функций:

1.  **Повторное использование кода**: Позволяет описать последовательность операторов один раз и вызывать её многократно из разных частей программы.
2.  **Модульность**: Разбиение большой программы на более мелкие, управляемые и тестируемые части. Это упрощает разработку, отладку и сопровождение кода.
3.  **Абстракция**: Скрытие внутренней реализации задачи, позволяя сосредоточиться на том, *что* функция делает, а не на том, *как* она это делает.

### Структура функции

Каждая программа на Си обязательно должна содержать главную функцию `main()`, которая является **точкой входа** в программу.

Общий синтаксис определения функции:

```c
<тип_возвращаемого_значения> <имя_функции>(<формальные_параметры>)
{
    // Тело функции: последовательность операторов
    // ...
    // Оператор возврата значения (если функция не void)
    return <выражение>;
}
```

  * **`<тип_возвращаемого_значения>`**: Тип данных, который функция возвращает. Если не указан, по умолчанию считается `int` (в старых стандартах). Для функций, не возвращающих значение, используется тип **`void`**.
  * **`<имя_функции>`**: Идентификатор, по которому будет происходить вызов.
  * **`<формальные_параметры>`**: Список объявлений переменных (с указанием типа и имени), которые функция принимает в качестве входных данных. Если функция не принимает параметров, используется `(void)` или просто `()`.

-----

## 🔄 Параметры и передача данных

### Формальные и фактические параметры

  * **Формальные параметры (аргументы)**: Параметры, указанные в **определении** (заголовке) функции. Они действуют как локальные переменные внутри функции.
  * **Фактические параметры (аргументы)**: Значения или переменные, которые передаются функции в момент её **вызова**.

> **Важно:** Фактические параметры должны соответствовать формальным по **количеству**, **порядку следования** и **типу**.

### Механизм передачи аргументов (По значению)

В Си по умолчанию аргументы передаются **по значению** (Call by Value).

  * При вызове функции создаются **локальные копии** фактических параметров, и эти копии присваиваются формальным параметрам.
  * Любые изменения, сделанные с формальными параметрами внутри функции, **не влияют** на исходные фактические параметры вне функции.
  * **Исключение**: Массивы в Си при передаче в функцию автоматически преобразуются в указатель на первый элемент, что фактически является передачей по ссылке (Call by Reference).

### Оператор `return`

Оператор **`return`** выполняет две ключевые функции:

1.  **Возврат значения**: Завершает выполнение функции и возвращает значение, указанное в `<выражение>`, обратно в вызывающий код. Тип этого значения должен совпадать с `<тип_возвращаемого_значения>` функции.
2.  **Завершение функции**: Немедленно прекращает выполнение функции и передает управление обратно в точку вызова. В функциях типа `void` оператор `return;` может использоваться без выражения для досрочного выхода.

-----

## ⚙️ Область видимости (Scope)

### Глобальные и локальные переменные

  * **Локальные объекты**: Переменные, объявленные **внутри** функции (включая формальные параметры). Они доступны только в пределах этой функции. Время их жизни ограничено временем выполнения функции.
  * **Глобальные объекты**: Переменные, объявленные **вне** всех функций (обычно в начале файла). Они доступны для использования в **любой** функции программы (включая `main()`). Чрезмерное использование глобальных переменных считается плохой практикой, так как снижает модульность и усложняет отслеживание изменений.

-----

## 📝 Прототип функции (Объявление)

### Зачем нужен прототип?

В Си функция должна быть **известна** компилятору до того, как она будет вызвана.

  * Если функция **определена** до `main()` или других вызывающих функций, прототип не требуется.
  * Если функция **определена** *после* того, как она была вызвана (например, после `main()`), необходимо указать её **прототип** (или **объявление**) до первого вызова.

Прототип функции сообщает компилятору следующую информацию:

1.  Имя функции.
2.  Тип возвращаемого значения.
3.  Количество и типы формальных параметров.

### Синтаксис прототипа

Прототип выглядит так же, как заголовок функции, но заканчивается точкой с запятой (`;`). Имена формальных параметров в прототипе можно опустить, оставив только их типы.

```c
// Прототип: имена параметров не обязательны
int max(int, int);

// Или с именами:
int max(int a, int b);
```

-----

## 🛠️ Пример кода: Функция для поиска максимума

Рассмотрим улучшенный пример, демонстрирующий использование прототипа, локальных и фактических параметров.

```c
#include <stdio.h>

// 1. Прототип функции: сообщает компилятору о существовании max()
// перед ее вызовом в main().
int max(int a, int b);

int main()
{
    // Локальные переменные функции main()
    int x, y, z;

    printf("Введите два целых числа (x, y): ");
    
    // Ввод фактических параметров
    if (scanf("%d %d", &x, &y) != 2) {
        printf("Ошибка ввода.\n");
        return 1; // Завершение программы с кодом ошибки
    }
    
    // 2. Вызов функции: x и y - фактические параметры.
    // Возвращаемое значение присваивается локальной переменной z.
    z = max(x, y);

    printf("x = %d, y = %d\n", x, y);
    printf("Максимум (max) = %d\n", z);

    // В отличие от оригинального примера, conio.h и getch()
    // для современных консольных программ не требуются.
    return 0;
}

// 3. Определение функции:
// a и b - формальные параметры, являющиеся локальными копиями x и y.
int max(int a, int b) 
{ 
    // Локальная переменная функции max()
    int result; 
    
    if (a > b) {
        result = a;
    } else {
        result = b;
    }
    
    // Возврат значения и завершение функции
    return result; 
}
```

### Анализ примера

1.  **Прототип**: `int max(int a, int b);` позволяет компилятору корректно обработать вызов `max(x, y)` в `main()`, даже если определение `max()` находится ниже.
2.  **Передача по значению**: Значения `x` и `y` из `main()` **копируются** в `a` и `b` соответственно. Если бы мы изменили `a` или `b` внутри `max()`, это никак не повлияло бы на `x` и `y` в `main()`.
3.  **Возврат значения**: Оператор `return result;` возвращает вычисленный максимум, который затем присваивается переменной `z` в `main()`.

# 🔄 2 Лекция: Рекурсия в языке Си

## 🎯 Цель лекции

Изучение принципов **рекурсивного программирования** в языке Си, понимание механизма работы рекурсивных функций и оценка их эффективности.

-----

## 🧠 Основные принципы рекурсии

### Что такое рекурсия?

**Рекурсия** — это свойство функции вызывать **саму себя** непосредственно или опосредованно (через другую функцию). Это мощный метод программирования, который позволяет решать сложные задачи, выражая их через более простые, похожие подзадачи.

Рекурсивный подход идеально подходит для задач, которые изначально определяются **рекуррентно**, например:

  * Математические последовательности (факториал, числа Фибоначчи).
  * Обход древовидных структур (каталоги файловой системы, узлы дерева).
  * Алгоритмы сортировки и поиска (Merge Sort, Quick Sort).

### Структура рекурсивной функции

Каждая корректная рекурсивная функция должна состоять из двух обязательных частей:

1.  **Базовый случай (Условие выхода)**: Это простейший случай, для которого результат известен и не требует дальнейших рекурсивных вызовов. Это **обязательное** условие, которое предотвращает **бесконечное зацикливание**.
2.  **Рекурсивный шаг**: Часть функции, где происходит вызов самой себя, но уже с **измененными** (уменьшенными или упрощенными) аргументами, которые приближают функцию к базовому случаю.

-----

## 📜 Примеры рекурсивных алгоритмов

### 1\. Вычисление факториала ($n!$)

Факториал определяется рекуррентно:

  * Базовый случай: $0! = 1$
  * Рекурсивный шаг: $n! = n \cdot (n-1)!$ для $n > 0$

**Код реализации:**

```c
long fact(int n)
{
    // Базовый случай: условие окончания рекурсии
    if (n <= 0) {
        return 1;
    } 
    // Рекурсивный шаг: вызов fact() с уменьшенным аргументом (n-1)
    else {
        return n * fact(n - 1); // Функция fact вызывает саму себя
    }
}
```

### 2\. Числа Фибоначчи ($F_i$)

Числа Фибоначчи задаются следующим образом:

  * Базовые случаи: $F_0 = 0$, $F_1 = 1$
  * Рекурсивный шаг: $F_i = F_{i-1} + F_{i-2}$ для $i > 1$

**Код реализации:**

```c
int Fib(int n)
{
    // Базовые случаи
    if (n == 0) return 0;
    if (n == 1) return 1;
    
    // Рекурсивный шаг: каждый вызов порождает два новых вызова
    return Fib(n - 1) + Fib(n - 2);
}
```

> **Примечание:** Как указано в исходном материале, этот рекурсивный подход, хотя и лаконичен, **неэффективен** из-за **повторного вычисления** одних и тех же значений ($F_{n-2}$, $F_{n-3}$ и т.д.) множество раз.

-----

## 🏗️ Механизм работы и проблемы

### Стек вызовов (Call Stack)

При каждом новом рекурсивном вызове происходит следующее:

1.  **Сохранение состояния**: Текущее состояние (адрес возврата, значения регистров) вызывающей функции запоминается.
2.  **Создание нового кадра стека**: В **стековой памяти** (Call Stack) создается новый **стековый кадр** (Stack Frame).
3.  **Локальные переменные**: В этом новом кадре создается **новый, независимый набор локальных переменных** и формальных параметров для текущего вызова функции.

Когда функция достигает базового случая и начинает возвращать значения (с помощью `return`), кадры стека последовательно **выгружаются** в обратном порядке вызова, пока не будет возвращен окончательный результат.

[Image of a call stack diagram showing frames for recursive function calls]

### Недостатки и опасность рекурсии

Рекурсия, несмотря на свою элегантность, имеет существенные недостатки, связанные с производительностью и памятью:

1.  **Переполнение стека (Stack Overflow)**:
      * При каждом рекурсивном вызове расходуется дополнительная память стека.
      * Если **глубина рекурсии** (количество вложенных вызовов) становится слишком большой, стек может **переполниться**, что приведет к аварийному завершению программы.
2.  **Накладные расходы (Overhead)**:
      * Вызов функции (сохранение состояния, передача параметров, создание кадра стека) занимает больше времени, чем простое выполнение цикла.
      * Следовательно, итеративный (циклический) подход, если он легко реализуем, почти всегда **более быстрый** и **эффективный** по памяти, чем рекурсивный.

> **Правило:** Если задача может быть легко и понятно решена с помощью цикла (итерации), **следует избегать рекурсии**. Рекурсия оправдана, когда итеративное решение значительно сложнее или менее интуитивно понятно (например, для обхода деревьев).

### Косвенная рекурсия

Существует и более сложная конструкция — **косвенная рекурсия**. Это происходит, когда функция вызывает сама себя не напрямую, а через одну или несколько других функций:

  * Функция `A` вызывает функцию `B`.
  * Функция `B` вызывает функцию `C`.
  * Функция `C` вызывает функцию `A` (замыкая рекурсивную цепь).

-----

## 🚀 Итерация vs. Рекурсия

| Характеристика | Рекурсия | Итерация (Циклы) |
| :--- | :--- | :--- |
| **Компактность** | Высокая, элегантная запись. | Запись может быть более громоздкой. |
| **Производительность** | Ниже: накладные расходы на вызовы функций. | Выше: минимальные накладные расходы. |
| **Память** | Расход стековой памяти (опасность переполнения). | Расход минимален (только для локальных переменных). |
| **Понятность** | Идеальна для рекуррентно определённых задач. | Идеальна для простых, последовательных задач. |

# 💾 3 Лекция: Работа с одномерными динамическими массивами

## 🎯 Цель лекции

Изучение принципов **динамического управления памятью** в языках Си и C++ и приобретение навыков работы с **динамическими одномерными массивами**.

-----

## 🌟 Основные сведения

### Что такое динамический массив?

**Динамический массив** — это массив, размер которого не фиксируется на этапе компиляции, а определяется **во время выполнения программы** (run-time) на основе входных данных или логики программы.

В отличие от статических массивов (например, `int arr[10];`), динамические массивы позволяют программисту самому управлять ресурсами памяти, используя так называемую **кучу** (Heap) — область памяти, доступную для динамического выделения.

### 📌 Роль указателей

Для работы с динамической памятью необходимо использовать **указатели**.

  * **Указатель** — это специальный тип переменной, которая хранит не само значение, а **адрес** (местоположение) другой переменной или блока данных в памяти.
  * **Объявление:** Указатель объявляется с помощью знака `*` перед его именем:
    ```c
    <тип_данных> *<имя_указателя>; 
    // Пример: int *p; // Указатель на целое число
    ```
  * В динамическом массиве указатель (`p`) хранит **адрес первого элемента** массива.

-----

## 🛠️ Управление памятью в Си (stdlib.h)

Для динамического управления памятью в стандартном языке **Си** используются функции из заголовочного файла `<stdlib.h>`.

### 1\. Выделение памяти

| Функция | Назначение | Синтаксис |
| :--- | :--- | :--- |
| **`malloc()`** (Memory Allocation) | Выделяет блок памяти указанного размера (в байтах). Память **не инициализируется** (содержит "мусор"). | `void *malloc(size_t size);` |
| **`calloc()`** (Contiguous Allocation)| Выделяет память для массива из $n$ элементов, каждый размером `size` байт. Вся выделенная память **обнуляется** (инициализируется нулями). | `void *calloc(size_t n, size_t size);` |

**Пример использования `malloc()`:**

```c
#include <stdlib.h> // Необходим для malloc и free

int n = 5; 
int *p; // Указатель на целое

// Выделяем память под n целых чисел. sizeof(int) определяет размер типа int в байтах.
p = (int *) malloc(n * sizeof(int)); 
// (int *) - явное приведение типа, т.к. malloc возвращает void*
```

### 2\. Освобождение памяти

После завершения работы с динамическим массивом необходимо **обязательно** освободить выделенную память, чтобы избежать **утечек памяти** (Memory Leaks).

  * **`free()`**: Освобождает блок памяти, на который указывает указатель.
    ```c
    free(p);
    ```
  * **Проверка после освобождения**: После вызова `free(p)`, указатель `p` становится **висячим** (Dangling Pointer) — он все еще содержит старый адрес, но память по этому адресу уже свободна и может быть использована ОС. Чтобы избежать ошибок, **всегда обнуляйте указатель** после освобождения памяти:
    ```c
    p = NULL;
    ```

### 3\. Обработка ошибок

После выделения памяти **необходимо** проверить, успешно ли прошла операция. Если память выделить не удалось (например, из-за нехватки системных ресурсов), функция `malloc` или `calloc` возвращает **`NULL`**.

```c
if (p == NULL) 
{
    printf("Не удалось выделить память.\n");
    return 1; // Выход с кодом ошибки
}
```

## 🧱 Управление памятью в C++ (`new` и `delete`)

В C++ для более безопасного и простого управления динамической памятью используются операторы `new` и `delete`.

### 1\. Выделение памяти (`new`)

Для выделения памяти под одномерный массив:

```cpp
int *p; // Указатель на целое
int n = 5; 

// Выделение памяти под n целых чисел
p = new int[n]; 
```

  * Оператор `new` автоматически возвращает указатель нужного типа, поэтому явное приведение типа (`(int *)`) не требуется.
  * Если выделение памяти завершается неудачей, `new` обычно генерирует исключение `std::bad_alloc`, хотя старые компиляторы могут возвращать `NULL` (как в приведенном примере).

### 2\. Освобождение памяти (`delete`)

Для освобождения динамического массива, выделенного через `new []`, используется оператор `delete []`:

```cpp
delete [] p; // Важно использовать квадратные скобки для массива!
p = NULL;    // Обнуляем указатель
```

> **Внимание:** Использование `delete p;` вместо `delete [] p;` для массива может привести к **неопределенному поведению** и утечкам памяти.

-----

## 🧑‍💻 Пример: Динамический массив (Си)

В приведенном примере на Си используется `malloc()`, и это корректно.

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{ 
    float *p; // Указатель на вещественные числа
    int i, n;
    
    printf("\n Размер массива: ");
    if (scanf("%d", &n) != 1 || n <= 0) {
        printf("Некорректный размер.\n");
        return 1;
    }
    
    // Выделение памяти под n вещественных чисел
    p = (float *) malloc(n * sizeof(float));
    
    if (p == NULL) // Проверка успешности выделения
    { 
        printf("Не удалось выделить память.");
        return 1;
    }
    
    // 1. Заполнение массива (доступ по индексу)
    for (i = 0; i < n; i++)
    { 
        printf("p[%d]=", i);
        scanf("%f", &p[i]);
    }
    
    // 2. Вывод массива
    printf("\nЭлементы массива:\n");
    for (i = 0; i < n; i++) 
        printf("\t p[%d]=%8.2f\n", i, p[i]);
    
    // 3. Освобождение и обнуление
    free(p);
    p = NULL;
    
    return 0;
}
```

## 🔢 Указательная арифметика и индексирование

Работа с динамическим массивом через указатель позволяет использовать либо стандартное индексирование (как со статическими массивами), либо **указательную арифметику**.

### Эквивалентность записей

Имя указателя `p` (хранящее адрес начала массива) **эквивалентно** адресу первого элемента массива `&p[0]`.

Доступ к $i$-му элементу массива может быть реализован тремя эквивалентными способами:

1.  **Индексирование (Array Indexing)**: `p[i]`
2.  **Получение адреса (Address Arithmetic)**: `(p + i)`
      * При добавлении целого числа $i$ к указателю `p`, адрес сдвигается не на $i$ байт, а на $i \times \text{sizeof}(\text{тип\_указателя})$ байт.
3.  **Разыменование (Dereferencing with Arithmetic)**: `*(p + i)`
      * Оператор `*` (разыменование) извлекает значение, хранящееся по адресу `(p + i)`.

| Операция | Индексирование | Указательная арифметика |
| :--- | :--- | :--- |
| **Значение** $i$-го элемента | `p[i]` | `*(p + i)` |
| **Адрес** $i$-го элемента | `&p[i]` | `(p + i)` |

### Пример: Инвертирование массива через указатели

В следующем примере для доступа к элементам используется исключительно указательная арифметика `*(p + i)`.

```c
#include <stdlib.h>
#include <stdio.h>

int main()
{ 
    int i, n, temp; // Имя переменной 's' заменено на 'temp' для ясности
    int *p;
    
    printf(" Размер массива -> "); 
    scanf("%d", &n); 
    
    // В Си++ используем 'new'
    p = (int *)malloc(n * sizeof(int)); // В данном контексте лучше использовать malloc
    
    if (p == NULL) 
    { 
        printf(" Не выделена память ");
        return 1; 
    }
    
    // Заполнение массива случайными числами
    printf("\nИсходный массив:\n");
    for (i = 0; i < n; i++) 
    { 
        // Присвоение значения i-му элементу
        *(p + i) = rand() % 20;
        printf(" p[%d] = %d\n", i, *(p + i));
    }
    
    // Инвертирование массива (обмен элементов местами)
    for (i = 0; i < n / 2; i++)
    { 
        temp = *(p + i);               // temp = значение первого элемента
        *(p + i) = *(p + (n - i - 1)); // Первый элемент = значение последнего
        *(p + (n - i - 1)) = temp;     // Последний элемент = исходное значение первого
    } 
    
    // Вывод инвертированного массива
    printf("\nИнвертированный массив:\n");
    for (i = 0; i < n; i++) 
        printf(" p[%d] = %d\n", i, *(p + i));
    
    free(p); // Освобождение памяти (для кода Си)
    p = NULL;
    
    return 0;
}
```

# 📊 4 Лекция: Двумерные динамические массивы (Матрицы)

## 🎯 Цель лекции

Изучение методов динамического выделения памяти для **двумерных массивов (матриц)** в Си и C++ и приобретение практических навыков работы с динамически распределенными матрицами.

-----

## 💡 Основные сведения: Представление матриц

В языках Си и C++ двумерные массивы могут быть представлены двумя основными способами, когда требуется динамическое выделение памяти:

### 1\. Метод "Массив строк" (Имитация статического массива)

Этот метод применим, когда **размер столбца (длина строки)** известен на этапе компиляции (т.е., является константой), но **количество строк** определяется во время выполнения.

  * В этом случае память выделяется как единый, непрерывный блок, достаточный для хранения всех элементов матрицы.
  * Мы объявляем **указатель на тип "строка"**.

#### Техника `typedef`

Для упрощения работы и имитации статического массива используется оператор `typedef`:

```c
const int N = 5;       // Известное количество столбцов
typedef int rown[N];   // rown — это новый тип: массив из N целых чисел
rown *a;               // Указатель на тип "строка"
```

  * Здесь `a` является указателем на элемент типа `rown`. Когда мы выделяем память под `m` элементов типа `rown`, мы получаем единый блок памяти для $m \times N$ элементов.

#### Выделение памяти (C++ `new`):

```cpp
a = new rown[m]; // Выделяем память под m строк, каждая из которых имеет N элементов.
```

  * **Преимущество:** Доступ к элементам (`a[i][j]`) и управление памятью (`delete a;`) просты и похожи на статические массивы. Память выделена **непрерывно**, что лучше для кэша процессора и производительности.

#### Освобождение памяти (C++ `delete`):

```cpp
delete [] a; // Освобождение единого блока памяти.
```

-----

## 🔗 2. Метод "Указатель на указатель" (Самый гибкий)

Этот метод является наиболее общим и необходим, когда **ни количество строк, ни количество столбцов не известны** на этапе компиляции.

  * Матрица представляется как **массив указателей**, где каждый указатель указывает на начало своей строки.
  * Это требует **двух шагов** выделения памяти, и память будет **непрерывна только внутри каждой строки**, но не между строками.

### Шаги выделения памяти:

1.  **Выделение памяти под массив указателей:**

      * Объявляется **указатель на указатель**: `int **a;`
      * Выделяется память для **$m$ указателей** (по одному указателю на каждую строку):
        ```c
        // В Си
        a = (int **)malloc(m * sizeof(int *)); 
        // В C++
        a = new int *[m]; 
        ```

2.  **Выделение памяти под каждую строку:**

      * В цикле для каждого указателя выделяется память под **$n$ элементов** (элементы самой строки):
        ```c
        for (int i = 0; i < m; i++) {
            // В Си
            a[i] = (int *)malloc(n * sizeof(int));
            // В C++
            a[i] = new int[n];
        }
        ```

### Освобождение памяти:

Освобождение памяти также требует **двух шагов** и должно производиться **в обратном порядке**:

1.  **Освобождение каждой строки (внутренний цикл):**

    ```c
    for (int i = 0; i < m; i++) {
        free(a[i]); // или delete [] a[i];
    }
    ```

2.  **Освобождение массива указателей (внешний блок):**

    ```c
    free(a); // или delete [] a;
    ```

### Доступ к элементам:

Доступ к элементу остается простым и интуитивно понятным, как и в статическом массиве:

  * **`a[i][j]`**

-----

## 🚀 Пример: Использование метода "Массив строк"

Пример демонстрирует первый, более простой метод (Массив строк), где $N$ (количество столбцов) фиксировано, а $M$ (количество строк) динамически вводится пользователем.

> **Примечание:** В примере используется C++-стиль выделения (`new/delete`) в функции `main()` без указания типа возвращаемого значения, что является особенностью старых стандартов Си/C++.

```c
#include <stdio.h>
#include <stdlib.h> // Для rand(), malloc/free, system("PAUSE")

// КОНСТАНТНЫЙ РАЗМЕР СТРОКИ
const int N=5; 
// 1. Определение нового типа: rown - это массив из N целых чисел
typedef int rown[N];

// Используем int main() для современных стандартов
int main()
{
    int i, j, m;
    rown *a; // Указатель на тип "строка" (для матрицы)
    int *b;  // Указатель на целое (для одномерного массива сумм)
    
    printf ( "Число строк (M)? ");
    // Ввод количества строк (динамический размер)
    if (scanf("%d", &m) != 1 || m <= 0) {
        printf("Некорректный ввод M.\n");
        return 1;
    }
    
    // 2. ВЫДЕЛЕНИЕ ПАМЯТИ: Единый блок (метод "Массив строк")
    a = new rown[m]; 
    if (a == NULL) { 
        printf("Не удалось выделить память для матрицы.");
        return 1;
    }
    
    // Выделение памяти под массив сумм (m элементов)
    b = new int[m]; 
    if (b == NULL) { 
        printf("Не удалось выделить память для массива сумм.");
        delete [] a; // Освобождаем матрицу перед выходом!
        return 1;
    }

    // 3. ЗАПОЛНЕНИЕ И ВЫВОД МАТРИЦЫ
    printf("\nСгенерированная матрица (%d x %d):\n", m, N);
    for (i = 0; i < m; i++)
    {
        int sum_row = 0;
        for (j = 0; j < N; j++)
        { 
            // Доступ: a[i][j]
            a[i][j] = rand() % 11; // 0..10
            printf("%4d", a[i][j]);
            sum_row += a[i][j];
        }
        b[i] = sum_row; // Запись суммы строки в массив b
        printf("  | Сумма: %d\n", b[i]);
    }
    
    // 4. ВЫВОД МАССИВА СУММ
    printf("\nМассив сумм строк (b):\n");
    for (i = 0; i < m; i++) 
        printf("%4d", b[i]);
    puts("\n");
    
    // 5. ОСВОБОЖДЕНИЕ ПАМЯТИ (Обязательно!)
    delete [] a; // Освобождение единого блока для матрицы
    delete [] b; // Освобождение массива сумм
    a = NULL;
    b = NULL;
    
    system("PAUSE");
    return 0;
}
```

# 🔗 5 Лекция: Многомерные динамические массивы: Указатель на Указатель

## 🎯 Цель лекции

Изучение и приобретение практических навыков создания, обработки и корректного освобождения памяти для **многомерных динамических массивов** (матриц) с произвольным (неизвестным на этапе компиляции) количеством строк и столбцов.

-----

## 💡 Основные сведения: Гибкое динамическое выделение

### Концепция "Указатель на указатель"

Для создания двумерной матрицы $M \times N$, где $M$ (количество строк) и $N$ (количество столбцов) неизвестны заранее, используется структура **указателя на указатель** (`**`).

По сути, мы создаем массив, каждый элемент которого является указателем на другую строку-массив.

  * **`float **matr;`**: Здесь `matr` — это указатель на `float *`.
      * `matr` хранит адрес начала первого массива (который содержит адреса начала строк).
      * `matr[i]` хранит адрес начала $i$-й строки.
      * `matr[i][j]` — это само значение элемента.

### Алгоритм создания и обработки двумерного массива

Создание такого массива всегда требует **двух этапов** выделения памяти, а освобождение — **двух этапов** очистки, в обратном порядке.

#### 1\. Объявление и ввод размеров

  * **Объявление:** Определяем указатель на указатель.
    ```c
    <тип> **uk; // Например: float **matr;
    ```
  * **Ввод размеров:** Читаем количество строк $M$ и столбцов $N$.

#### 2\. Выделение памяти под массив указателей (Строка 0)

Это первый этап. Выделяется память под одномерный массив, который будет хранить **адреса начала каждой строки**.

  * **Си-стиль (`malloc`):**
    ```c
    uk = (<тип> **)malloc(m * sizeof(<тип> *)); 
    ```
  * **C++-стиль (`new`):**
    ```cpp
    uk = new <тип> *[m]; 
    ```

#### 3\. Выделение памяти под каждую строку (M строк)

Это второй этап. В цикле для каждого элемента массива указателей (`uk[i]`) выделяется память под $N$ элементов — то есть под саму строку.

  * **Цикл выделения:**
    ```c
    for (i = 0; i < m; i++) 
    {
        // Си-стиль
        uk[i] = (<тип> *)malloc(n * sizeof(<тип>));
        // C++-стиль
        uk[i] = new <тип>[n];
        // Обязательная проверка на NULL после каждого выделения!
    }
    ```

#### 4\. Обработка массива

Работа с элементами массива происходит интуитивно, как со статическим массивом:

  * **`uk[i][j]`**
      * Индексирование `uk[i]` автоматически разыменовывает указатель в массиве указателей, получая адрес строки.
      * Дальнейшее индексирование `[j]` обращается к конкретному элементу в этой строке.

#### 5\. Освобождение памяти (Обязательный двухэтапный процесс)

Для предотвращения утечек памяти освобождение происходит **в обратном порядке** выделению: сначала строки, затем массив указателей.

  * **Этап 1: Освобождение каждой строки**

    ```c
    for (i = 0; i < m; i++) 
    {
        free(uk[i]);   // или delete [] uk[i]; в C++
        uk[i] = NULL;
    }
    ```

  * **Этап 2: Освобождение массива указателей**

    ```c
    free(uk);          // или delete [] uk; в C++
    uk = NULL;
    ```

### Использование `typedef` для упрощения

Использование `typedef` может сделать синтаксис объявления более читабельным, но не меняет суть двухуровневой структуры:

```c
typedef int *pInt; // pInt - это указатель на int
pInt *uk;          // uk - это указатель на pInt (то есть указатель на указатель на int)
```

## 🧑‍💻 Пример: Создание матрицы с произвольными размерами

В этом примере используется C++-стиль выделения памяти (`new`/`delete`) для двумерной матрицы с произвольными размерами $M$ и $N$.

```c
#include <stdio.h>
#include <stdlib.h> // Для rand() и system()
#include <conio.h>  // Для getch() (хотя в современных системах лучше избегать)

int main()
{ 
    int m, n, j, i;
    // Объявляем **matr — указатель на float* (указатель на указатель)
    float **matr; 
    float *mass; // Для одномерного массива сумм строк
    
    system("CLS"); // Очистка экрана
    
    printf("Введите количество строк m: "); 
    if (scanf("%d", &m) != 1 || m <= 0) return 1;
    
    printf("Введите размер столбца n: "); 
    if (scanf("%d", &n) != 1 || n <= 0) return 1;

    // --- 1. Выделение памяти ---
    
    // Выделяем память под массив сумм строк (M элементов)
    mass = new float[m]; 
    if (mass == NULL) { puts("Ошибка: Не создан массив сумм!"); return 1; }
    
    // Этап 1: Выделяем память под массив указателей (M указателей)
    matr = new float *[m]; 
    if (matr == NULL) { 
        puts("Ошибка: Не создан массив указателей!"); 
        delete [] mass; 
        return 1; 
    } 
    
    // Этап 2: В цикле выделяем память под каждую строку (N элементов)
    for (i = 0; i < m; i++)
    { 
        matr[i] = new float[n]; // Выделяем память под i-ю строку 
        if (matr[i] == NULL)
        { 
            puts("Ошибка: Не создана динамическая строка!"); 
            // В случае ошибки здесь нужно корректно освободить уже выделенные строки!
            for (int k = 0; k < i; k++) delete [] matr[k];
            delete [] matr;
            delete [] mass;
            return 1; 
        }
        for (j = 0; j < n; j++) 
            matr[i][j] = (float)(rand() % 100) / 10.0f; // Заполняем дробными числами (0.0..9.9)
    }

    // --- 2. Обработка и вывод ---
    
    printf("\nСгенерированная матрица:\n");
    for (i = 0; i < m; i++)
    { 
        mass[i] = 0;
        for (j = 0; j < n; j++)
        {
            printf("%8.2f", matr[i][j]);
            mass[i] += matr[i][j]; // Помещаем сумму i-й строки в одномерный массив
        }
        printf("\n");
    }
    
    // Вывод сумм
    printf("\nСуммы строк:\n");
    for (i = 0; i < m; i++) 
        printf(" Сумма %d строки: %8.2f\n", i, mass[i]);

    // --- 3. Освобождение памяти ---
    
    // Этап 1: Освобождаем память M строк
    for (i = 0; i < m; i++)
    { 
        delete [] matr[i]; 
        matr[i] = NULL;
    }
    
    // Этап 2: Освобождаем память массива указателей
    delete [] matr; 
    matr = NULL;
    
    // Освобождаем массив сумм
    delete [] mass; 
    mass = NULL;
    
    getch();
    return 0;
}
```

-----

## ⚠️ Важность корректного освобождения

При работе с двумерными динамическими массивами, выделенными методом "указатель на указатель", **критически важно** выполнять двухэтапное освобождение:

1.  **Сначала** освобождаются **внутренние блоки** (строки). Если пропустить этот шаг, то память строк будет потеряна (утечка памяти), а указатели на них — недоступны.
2.  **Затем** освобождается **внешний блок** (массив указателей).

# 🔄 6 Лекция: Функции: Передача параметров по адресу и ссылке

## 🎯 Цель лекции

Изучение методов **передачи изменяемых параметров** в функции (Call by Reference) с использованием **указателей** (в Си/C++) и **ссылок** (в C++), а также понимание различий и областей их применения.

-----

## 💡 Основные сведения: Необходимость изменения параметров

В предыдущих лекциях мы изучили **передачу по значению** (Call by Value), при которой функция получает лишь **копии** фактических аргументов и не может изменить исходные переменные.

Однако часто необходимо:

1.  Дать функции возможность **изменить** значение переменной, переданной из вызывающей программы.
2.  **Вернуть несколько результатов** из функции, так как через имя функции можно вернуть только одно значение.

Для достижения этой цели используются **передача по адресу** (указатели) и **передача по ссылке** (ссылки C++).

-----

## 1\. ⚙️ Передача параметров по адресу (Указатели)

Метод "передачи по адресу" (Pass by Address) используется как в **Си**, так и в **C++**. Мы передаем функции не само значение переменной, а **адрес** ее местоположения в памяти.

### Механизм

  * **Формальный параметр**: В заголовке функции объявляется **указатель** (`*x`).
  * **Вызов функции**: В качестве фактического параметра передается **адрес** переменной (`&z`) с помощью оператора взятия адреса **амперсанд** (`&`).
  * **Внутри функции**: Для доступа к содержимому по адресу используется оператор **разыменования** **звездочка** (`*`).

### Пример (Си/C++): Функция `prim`

```c
void prim(int *x) // x — указатель на int
{
    // Разыменовываем указатель, чтобы изменить СОДЕРЖИМОЕ по адресу
    *x = 10; 
}

int main() 
{
    int z = 5;
    prim(&z); // Передаем адрес переменной z
    // z теперь равно 10
}
```

### Пример: Обмен значениями (`swap`)

Передача по адресу идеально подходит для реализации функций, которые должны изменить две или более переменных, как, например, функция обмена значениями.

```c
void swap(float *a, float *b)
{
    float c;
    c = *a;  // c = содержимое по адресу a
    *a = *b; // Содержимое по адресу a = содержимому по адресу b
    *b = c;  // Содержимое по адресу b = c (исходное a)
}
// Вызов: swap(&x, &y);
```

### Недостатки указателей

1.  **Необходимость разыменования**: В теле функции необходимо постоянно использовать **`*`** для доступа к значению.
2.  **Синтаксическая сложность**: Легко забыть `&` при вызове или `*` внутри функции, что может привести к ошибкам (например, попытке изменить сам адрес, а не значение по нему).

-----

## 2\. ⚡ Передача параметров по ссылке (References)

Метод "передачи по ссылке" (Pass by Reference) является особенностью языка **C++** и предлагает более чистый и безопасный способ изменения параметров.

### Механизм

  * **Ссылка** (`&`) — это **псевдоним** или второе имя для уже существующей переменной.
  * **Формальный параметр**: В заголовке функции объявляется **ссылка** (`&x`).
  * **Вызов функции**: Переменная передается **как обычно** (`z`), без оператора `&`.
  * **Внутри функции**: Ссылочный параметр используется **как обычная переменная**, без оператора `*`. Компилятор сам неявно выполняет работу с адресами.

### Пример (C++): Функция `prim`

```cpp
void prim(int &x) // x — ссылка на int
{
    // x используется как обычная переменная; компилятор неявно работает с адресом z
    x = 17; 
}

int main() 
{
    int z = 5;
    prim(z); // Передаем переменную напрямую
    // z теперь равно 17
}
```

### Пример: Возврат нескольких результатов

Передача по ссылке идеально подходит для возврата нескольких значений, как в функции `MinMax`.

```cpp
void MinMax(int a, int b, int &min_val, int &max_val)
{
    // a и b переданы по значению (копии)
    // min_val и max_val переданы по ссылке (могут быть изменены)
    if (a > b) 
    {
        max_val = a; 
        min_val = b; 
    }
    else 
    {
        max_val = b; 
        min_val = a; 
    }
}
// Вызов: MinMax(x, y, min_res, max_res);
```

### Защита от изменений: `const` Ссылки

Основной недостаток ссылок — отсутствие явного указания в точке вызова на то, что переменная может быть изменена. Чтобы избежать случайного изменения параметра при передаче большого объекта (для эффективности), но при этом **гарантировать его неизменность**, используется квалификатор **`const`**:

```cpp
void print_data(const std::vector<int> &data);
// Функция гарантирует, что data не будет изменена.
```

-----

## 3\. ⚖️ Сравнение: Указатель vs. Ссылка

| Характеристика | Передача по адресу (Указатель) | Передача по ссылке (Ссылка C++) |
| :--- | :--- | :--- |
| **Синтаксис параметра** | `*a` | `&a` |
| **Синтаксис вызова** | `&x` (Требуется амперсанд) | `x` (Переменная напрямую) |
| **Внутри функции** | Требуется разыменование `*a` | Используется как обычная переменная `a` |
| **Обязательность** | Может быть `NULL` | Не может быть `NULL` (должна быть инициализирована) |
| **Гибкость** | Можно менять адрес, выполнять арифметику | Нельзя менять адрес (ссылка фиксирована) |
| **Читаемость** | Явно видно, что передается адрес | Менее очевидно, что переменная будет изменена |
| **Совместимость** | Си и C++ | Только C++ |

### Выбор метода

  * **Используйте Указатели**, если:
      * Пишете на **чистом Си** (где нет ссылок).
      * Вам нужна возможность передать **`NULL`** (отсутствие объекта).
      * Вам необходима **указательная арифметика** (например, при работе с массивами).
  * **Используйте Ссылки**, если:
      * Пишете на **C++**.
      * Нужен **чистый синтаксис** без `&` и `*`.
      * Вам нужно обеспечить, что переменная **не будет** `NULL`.

# 📦 7 Лекция: Массивы как параметры функций

## 🎯 Цель лекции

Изучение **особенностей передачи массивов** в функции в языке Си и C++, понимание того, как эта передача отличается от передачи обычных переменных, и освоение синтаксиса для одномерных и многомерных массивов.

-----

## 💡 Основные сведения: Передача по указателю

### Почему массивы особенные?

В отличие от скалярных переменных (например, `int` или `float`), которые передаются **по значению** (создается копия), **массив в Си/C++ никогда не передается по значению**.

Когда имя массива используется в качестве фактического параметра функции, компилятор автоматически преобразует его в **указатель на его первый (нулевой) элемент**.

Это означает, что передача массива — это всегда **передача по адресу (ссылке)**.

  * **Последствие**: Изменение элемента массива внутри функции **затрагивает сам исходный массив** в вызывающей программе.

### Эквивалентные объявления одномерных массивов

Поскольку передается только адрес первого элемента, компилятору не важен размер первого измерения массива. Все следующие объявления параметров функции для одномерного целочисленного массива `A` эквивалентны:

| Синтаксис | Описание | Применение |
| :--- | :--- | :--- |
| `void f(int A[])` | Описание как массива без размера. | Стандартный, наиболее читаемый способ. |
| `void f(int A[10])` | Описание как массива с указанием размера (размер игнорируется). | Допускается, но может вводить в заблуждение. |
| `void f(int *A)` | Описание как указателя на целое число. | Наиболее точное отражение механизма передачи. |

### Необходимость передачи размера

Поскольку при передаче теряется информация о размере массива, его **размер** должен быть передан в функцию как **дополнительный параметр**.

```c
// Правильная сигнатура для работы с одномерным массивом:
void print_array(int *arr, int size); 
// или 
void print_array(int arr[], int size);
```

### Защита от изменений: Квалификатор `const`

Если вы не хотите, чтобы функция меняла элементы переданного массива, но хотите использовать эффективную передачу по указателю, используйте квалификатор **`const`**:

```c
// Функция может читать элементы, но не может их изменять
void print(const int arr[], int size);
```

## 📐 Передача многомерных массивов

При передаче многомерных массивов в функцию необходимо, чтобы компилятор знал, как рассчитывать смещение (адрес) элементов в памяти.

  * В многомерном массиве элемент $A[i][j]$ вычисляется как $Адрес\_начала + i \cdot \text{размер\_строки} + j \cdot \text{размер\_элемента}$.
  * Для этого **правые границы всех измерений, кроме первого, должны быть заданы**.

### Синтаксис для двумерных массивов ($M \times N$)

Если у нас есть массив `int matrix[10][20]`, при передаче в функцию нужно указать размер столбца (второе измерение).

| Формальный параметр | Описание | Примечание |
| :--- | :--- | :--- |
| `void f(int matrix[][10], int rowSize)` | Объявление как двумерного массива. | Размер `rowSize` (количество строк) передается отдельно. |
| `void f(int (*matrix)[10], int rowSize)` | Эквивалентное объявление как указателя на массив из 10 элементов типа `int`. | **Скобки вокруг `*matrix` обязательны** из-за приоритета операторов. |

> **Внимание**: Объявление `int *matrix[10]` **не** эквивалентно. Оно объявляет `matrix` как **массив из 10 указателей**, а не как указатель на двумерный массив.

### Динамические массивы (`int **a`)

При передаче двумерного массива, выделенного методом "указатель на указатель" (`int **a`), формальный параметр функции также должен быть **указателем на указатель**:

```c
// Параметры: **a - матрица, n - строки, m - столбцы
void print_dynamic_matrix(int **a, int n, int m) {
    // ... работа с a[i][j] ...
}

// Вызов: print_dynamic_matrix(dynamic_array, rows, cols);
```

## 🛠️ Примеры: Реализация

### Пример 1: Сумма элементов одномерного массива

Функция `Sum` принимает массив (как указатель) и его размер. Изменение элементов не происходит.

```c
#include <stdio.h>
#include <stdlib.h>

int Sum (int A[], int N) // A[] - эквивалентно int *A
{ 
    int i, sum = 0;
    for (i = 0; i < N; i++)
        sum += A[i];
    return sum;
}

int main()
{
    const int n = 20, m = 30;
    int A[n], B[m];

    // ... Заполнение массивов A и B ...

    // Передаем имя массива и его размер
    int s_a = Sum(A, n); 
    int s_b = Sum(B, m);

    printf("\nСумма массива A %d, массива B %d\n", s_a, s_b); 
    return 0;
}
```

### Пример 2: Изменение элементов массива

Функция `quart` изменяет исходный массив `z`, возводя каждый его элемент в квадрат. Поскольку передача происходит по указателю, изменения сохраняются после выхода из функции.

```c
#include <stdio.h>

void quart(int n, float *x) // x — указатель на float
{ 
    int i;
    for (i = 0; i < n; i++)
        // Доступ через индексирование, хотя x — указатель.
        x[i] = x[i] * x[i]; 
}

int main()
{ 
    float z[] = {1.0f, 2.0f, 3.0f, 4.0f, 5.0f};
    
    // Вычисление размера массива в элементах
    int n = sizeof(z) / sizeof(z[0]); 
    
    // ... Вывод исходного массива ...
    
    // Передаем размер и имя массива (которое преобразуется в адрес)
    quart(n, z); 
    
    // ... Вывод измененного массива ...
    // Элементы z[] теперь равны 1.0, 4.0, 9.0, 16.0, 25.0
    
    return 0;
}
```

### Пример 3: Работа с многомерным массивом

В этом примере функция `MaxMin` принимает и изменяет четыре статических двумерных массива, используя синтаксис, требующий указания размера столбца (`n`).

```c
#include <stdio.h>
#include <stdlib.h>

const int n=4, m=4; // Размер столбца (n) должен быть константой

// Сигнатура функции:
// A, B - входные матрицы. C, D - выходные матрицы, где будут записаны результаты.
void MaxMin(int A[][n], int B[][n], int (*C)[n], int (*D)[n], int m)
{
    int i, j;
    // ... логика заполнения C и D ...
    
    // Внутри функции доступ к элементам: C[i][j], D[i][j]
    for (i = 0; i < m; i++)
    { 
        for (j = 0; j < n; j++)
        {
            if (A[i][j] > B[i][j])
            {
                C[i][j] = A[i][j]; // Максимум
                D[i][j] = B[i][j]; // Минимум
            }
            else
            { 
                C[i][j] = B[i][j];
                D[i][j] = A[i][j];
            }
        }
    }
}

int main()
{ 
    // Статические массивы M x N
    int A[m][n], B[m][n], C[m][n], D[m][n];

    // ... Заполнение A и B случайными числами ...
    
    // Вызов: передача имен массивов (преобразуются в указатели на массив из 'n' int)
    MaxMin(A, B, C, D, m); 
    
    // ... Вывод матриц C и D ...
    
    return 0;
}
```

# 🧱 8 Лекция: Структуры (Structures, `struct`) в Си/C++

## 🎯 Цель лекции

Изучение концепции **структур** как пользовательских типов данных, освоение синтаксиса их объявления, создания переменных-структур, доступа к их элементам и работы с **массивами структур**.

-----

## 💡 Основные сведения: Объединение данных

### Что такое структура?

**Структура** (`struct`) — это сложный, пользовательский тип данных, который позволяет объединить **фиксированное число элементов (полей)**, которые могут иметь **различные типы**.

В отличие от **массива**, который хранит коллекцию однотипных элементов, структура используется для логического объединения связанных, но разнородных данных в один объект (запись).

  * **Поля (Elements/Members)**: Элементы, входящие в состав структуры. Поля могут быть базовых типов (`int`, `char`), массивами, указателями или даже другими структурами.
  * **Использование**: Структуры являются фундаментальным инструментом для моделирования реальных сущностей, таких как "Работник" (имя, зарплата, дата рождения), "Книга" (название, автор, год), "Товар" (название, цена, количество).

### 1\. Объявление типа структуры

Описание структуры вводит только **шаблон** или **тип данных**. Никакая память под данные не выделяется до тех пор, пока не будет объявлена переменная этого типа.

**Форма объявления:**

```c
struct <имя_структуры> {
    <тип_1> <имя_поля_1>;
    <тип_2> <имя_поля_2>;
    // ...
}; // Не забывайте точку с запятой!
```

**Пример:**

```c
// card - имя типа структуры (метку)
struct card {
    char author[40]; // Массив символов (строка)
    char title[40];  // Строка
    int year;        // Целое число
    float cena;      // Вещественное число
}; 
```

### 2\. Объявление переменных-структур

Чтобы использовать структуру, необходимо объявить переменную этого типа:

```c
struct card Book;       // Объявление переменной Book типа struct card
struct card bibl[100];  // Объявление массива из 100 структур типа card
```

### 3\. Обращение к полям структуры

Доступ к отдельным полям структуры осуществляется с помощью **оператора точки** (`.`).

**Синтаксис:** `<имя_переменной\_структуры> . <имя\_поля>`

**Пример (доступ и присвоение):**

```c
struct card Book;

// Присвоение значений полям
strcpy(Book.author, "Довгаль С.И."); // Для строк используем strcpy()
Book.year = 2003;                   // Для числовых полей прямое присвоение
```

> **Важно:** Для копирования строк (массивов `char`) необходимо использовать функцию `strcpy()` из `<string.h>`, так как простое присвоение (`Book.title = "..."`) для массивов не работает.

-----

## 📝 Пример 1: Учет товаров (Массив структур)

Этот пример демонстрирует создание массива структур и использование оператора точки для доступа к полям каждого элемента.

```c
#include <stdio.h>
#include <string.h>
#define N 10

// Объявление типа структуры (вне main)
struct tov {
    char name[10];
    float c;    // цена
    int kol;    // количество
};

int main()
{
    // Объявление массива структур (массив записей)
    struct tov mag[N]; 
    char nazv[10]; // Наименование искомого товара
    int i, k = 0; 
    float sum = 0.0f; 

    // Ввод данных и заполнение массива mag[]
    for (i = 0; i < N; i++)
    { 
        printf("\n Введите наименование, цену, количество товара %d: ", i + 1);
        // Заполнение элементов массива структур
        if (scanf("%s %f %d", mag[i].name, &mag[i].c, &mag[i].kol) != 3) {
            // Обработка ошибок ввода
        } 
    }
    
    // Ввод искомого товара
    printf("\n Введите искомый товар: ");
    scanf("%s", nazv);
    
    // Поиск и подсчет общей стоимости
    for (i = 0; i < N; i++)
    {
        // Сравнение строк с помощью strcmp()
        if (strcmp(mag[i].name, nazv) == 0)
        {
            sum += mag[i].c * mag[i].kol;
            k++;
        }
    }
    
    printf("Товаров %s: %d, общая стоимость: %5.2f\n", nazv, k, sum);
    return 0;
}
```

### Присваивание структур

В Си/C++ можно присваивать одну переменную-структуру другой, если они имеют **один и тот же тип**. При этом происходит **почленное копирование** всех полей.

```c
struct card Book1;
struct card Book2;

// ... заполнение Book1 ...

Book2 = Book1; // Все поля из Book1 копируются в Book2
```

## 📚 Пример 2: Справочник (Использование справочных массивов)

Этот пример демонстрирует, как структура может ссылаться на данные из **внешнего справочного массива** для избежания дублирования информации (например, имен).

```c
#include <iostream>
#include <string.h>
#include <stdlib.h>
using namespace std;

#define N 10 // Количество записей
#define K 3  // Количество уникальных имен
// Справочный массив имен
char name[K][15] = {"Ivan", "Petr", "Pavel"}; 
 
struct zap {
    char fam[20];
    unsigned char n; // Индекс (0, 1, или 2) для массива name
    char tel[15];
};
 
int main() 
{
    // Инициализация массива структур с использованием индекса 'n'
    zap a[N] = {
        {"Petrov", rand() % K, "9139202020"}, 
        {"Petrov", rand() % K, "9139202021"},
        {"Ivanov", rand() % K, "9139202022"},
        // ... остальные записи ...
    };
    
    // Вывод записей
    for (int i = 0; i < N; i++) 
    {
        // Использование индекса a[i].n для получения имени из справочного массива
        cout << a[i].fam << " " << name[a[i].n] << " telefon " << a[i].tel << endl;
    }
    
    // Группировка и подсчет по именам (по полю 'n')
    int m[K] = {}; // Массив счетчиков, инициализированный нулями
    
    // Первый способ: Проход по записям и инкремент счетчика
    for (int i = 0; i < N; i++) 
        m[a[i].n]++; // Увеличиваем счетчик для соответствующего имени
        
    printf("\nСтатистика по именам:\n");
    // Вывод результатов
    for (int i = 0; i < K; i++)

    return 0;
}

# ⛓️ 9 Лекция: Списки и Деревья: Ссылочные типы данных и Динамические структуры

## 🎯 Цель лекции

Изучение принципов построения и работы со **ссылочными (динамическими) структурами данных**, включая **линейные списки** (стек, очередь, двусвязный список) и **нелинейные структуры** (двоичное дерево поиска).

-----

## 1\. 🔗 Линейные динамические списки

**Динамический список** — это последовательность узлов (структур), которые связаны между собой **указателями (ссылками)**. В отличие от массивов, списки могут изменять свой размер во время выполнения программы.

### Структура узла (Node)

Каждый элемент списка (узел) состоит из двух основных частей:

1.  **Информационная часть**: Содержит данные, подлежащие обработке (`char data[20]`, `int key` и т.д.).
2.  **Дополнительная часть**: Содержит **указатель** на следующий (и/или предыдущий) узел того же типа.

Для **односвязного** списка используется **самореферентная структура**:

```c
struct st {
    char data[20];
    struct st *next; // Указатель на следующий узел типа struct st
};
```

> **Узел-заголовок (Head)**: Часто используется дополнительный служебный узел (`head`), который не содержит данных, но указывает на первый фактический элемент списка. Это упрощает операции добавления и удаления в начале списка.

### Разновидности линейных списков

В зависимости от правил добавления и удаления элементов, линейные списки делятся на:

| Тип списка | Принцип доступа | Операции | Описание |
| :--- | :--- | :--- | :--- |
| **Стек** | **LIFO** (Last In, First Out) | Добавление/удаление (**Push/Pop**) происходит только в **начале** списка. | Представьте стопку книг — новую кладут сверху, и берут только верхнюю. |
| **Очередь** | **FIFO** (First In, First Out) | Удаление (**Dequeue**) происходит из **начала**, добавление (**Enqueue**) — в **конец** списка. | Как обычная очередь в магазине. |

### Пример: Создание Стека (Добавление в начало)

При добавлении нового элемента `p` в начало списка (`head`):

1.  Указатель `p->next` настраивается на первый фактический элемент (`head->next`).
2.  Указатель `head->next` перенастраивается на новый элемент `p`.

[Image of stack data structure push operation]

```c
// Создание узла
p = new spis;
scanf("%s", p->data);

// Логика добавления в начало (Push)
p->next = head->next; 
head->next = p;
```

### Двусвязные списки

В **двусвязном списке** каждый узел содержит две ссылки:

  * **`*next`**: Указатель на **следующий** узел.
  * **`*prev`**: Указатель на **предыдущий** узел.

<!-- end list -->

```c
struct spis {
    char data[80];
    spis *next, *prev;
};
```

**Преимущество**: Возможность быстрого перемещения в обоих направлениях и эффективное **удаление** элемента по его адресу, так как легко получить доступ к обоим соседним узлам для перенастройки их ссылок.

**Удаление узла `t` (из тела списка):**

```c
t->next->prev = t->prev; 
t->prev->next = t->next; 
delete(t); 
```

## 2\. 🌳 Деревья

**Дерево** — это нелинейная иерархическая структура, состоящая из узлов, связанных **ветвями**.

  * **Корень (Root)**: Начальный узел, который не имеет родителя.
  * **Ветви**: Соединяют родительские узлы с дочерними.

### Двоичное дерево (Binary Tree)

**Двоичное дерево** — это структура, в которой каждый узел имеет не более двух потомков (сыновей): **левого** и **правого**.

```c
struct tree {
    int key;    // Ключ (информационная часть)
    tree *l;    // Ссылка на левого сына (левое поддерево)
    tree *r;    // Ссылка на правого сына (правое поддерево)
};
```

[Image of a binary tree structure with root, nodes, and leaves]

### Двоичное дерево поиска (Binary Search Tree, BST)

Для обеспечения высокой скорости поиска, дерево строится по правилу упорядоченности:

1.  Все ключи в **левом поддереве** вершины $X$ **меньше** ключа $X$.
2.  Все ключи в **правом поддереве** вершины $X$ **больше или равны** ключу $X$.

#### Алгоритм построения (Добавление узлов)

Построение BST удобно реализовать с помощью **рекурсии**.

```c
// tree *&t — передача указателя t по ссылке, чтобы изменить его, если t == NULL.
void add (tree *&t, int data) {
    if (t == NULL) { // Если текущий узел пуст, создаем новый (базовый случай)
        t = new tree; 
        t->key = data;
        t->l = t->r = NULL;
        return;
    }
    if (data < t->key) // Если меньше, идем влево
        add(t->l, data);
    else // Если больше или равно, идем вправо
        add(t->r, data);
}
```

#### Обход дерева (Tree Traversal)

Обход — это посещение каждого узла в определенном порядке. Обходы используются для вывода информации и других операций.

1.  **ЛКП обход (Inorder Traversal: Лево - Корень - Право)**

      * **Последовательность**: `print_t(t->l)` -\> `printf("%d ", t->key)` -\> `print_t(t->r)`.
      * **Свойство BST**: Узлы будут пройдены **в порядке возрастания** ключей.

2.  **ПКЛ обход (Reverse Inorder Traversal: Право - Корень - Лево)**

      * **Последовательность**: `print_t(t->r)` -\> `printf("%d ", t->key)` -\> `print_t(t->l)`.
      * **Свойство BST**: Узлы будут пройдены **в порядке убывания** ключей.

#### Алгоритм поиска по дереву

Поиск также выполняется рекурсивно, используя свойство упорядоченности BST:

```c
tree * search (tree * t, int x) {
    if (!t || x == t->key) // Узел не найден или ключ совпал
        return t; 
    
    if (x < t->key) // Ищем в левом поддереве
        return search(t->l, x);
    
    return search(t->r, x); // Ищем в правом поддереве
}
```

-----

## 💾 Основные понятия и режимы работы

### Файл и Поток

  * **Файл**: Упорядоченная последовательность однотипных компонентов, хранящаяся на **внешнем носителе**. Файлы используются для **долговременного хранения данных**, обработки **больших массивов** и обеспечения **общего доступа** для разных программ.
  * **Поток (Stream)**: Абстракция в Си/C++, представляющая собой упорядоченную последовательность байтов, которая может быть связана как с файлом на диске, так и с устройством ввода/вывода (клавиатура, дисплей).

### Указатель на файл (`FILE*`)

Для управления потоком в программе используется переменная-указатель на предопределенную структуру **`FILE`** (описана в `<stdio.h>`).

```c
FILE *pf; // Объявление указателя на файловый поток
```

Функция **`fopen()`** возвращает указатель на структуру `FILE` при успешном открытии или **`NULL`** в случае ошибки.

### Режимы работы с файлами

В Си потоки открываются либо в **текстовом**, либо в **двоичном (бинарном)** режиме.

| Режим | Описание | Особенности |
| :--- | :--- | :--- |
| **Текстовый (`t`)** | Предназначен для работы с символьной информацией (текст). | Выполняет **преобразование** символов конца строки: последовательность **CR (0x0D) + LF (0x0A)** (используется в Windows) преобразуется в один символ **`\n`** при чтении, и обратно — при записи. Чтение может прерваться при символе **EOF (0x1A)**. |
| **Двоичный (`b`)** | Предназначен для хранения числовых данных, структур. | **Не выполняет преобразований** и не анализирует данные. Чтение продолжается до физического конца файла. **Используется для сохранения данных без потери точности.** |

### Основные режимы открытия (`fopen`)

Базовый режим открытия файла определяется строкой-аргументом, которая может включать `t` (текст) или `b` (двоичный) как суффикс (например, `"rb"`, `"wt"`).

| Режим | Назначение | Описание действия |
| :--- | :--- | :--- |
| **`"r"`** | Чтение | Файл должен существовать. |
| **`"w"`** | Запись | **Создает** новый файл. Если файл существует, его содержимое **удаляется**. |
| **`"a"`** | Дополнение | Запись происходит только **в конец** существующего файла. Если файла нет, он создается. |
| **`"r+"`** | Чтение и запись | Для существующего файла. |
| **`"w+"`** | Чтение и запись | **Создает** новый файл или **стирает** существующий. |
| **`"a+"`** | Чтение и дополнение | Чтение с начала, запись в конец. |

## 💻 Пример 1: Фильтрация символов

Программа демонстрирует создание, запись, чтение и фильтрацию содержимого текстового файла.

```c
#include <stdio.h>
#include <string.h>

int main()
{ 
    char ch, sl[50];
    char text[] = "one two three four";
    FILE *pf, *pr; // Указатели на файлы

    // 1. Создание и запись в new1.txt (режим "w" - перезапись)
    pf = fopen("new1.txt", "w"); 
    if (pf == NULL) { printf("Ошибка открытия new1.txt\n"); return 1; }
    fputs(text, pf); // Запись строки (без добавления \n)
    fclose(pf); 

    // 2. Чтение new1.txt и запись в new2.txt (фильтрация пробелов)
    pf = fopen("new1.txt", "r"); // Чтение
    pr = fopen("new2.txt", "w"); // Запись
    if (pf == NULL || pr == NULL) { printf("Ошибка открытия файлов\n"); return 1; }
    
    // Посимвольное чтение до конца файла (EOF)
    while ((ch = fgetc(pf)) != EOF) 
    { 
        if (ch != ' ') // Фильтруем пробелы
            fputc(ch, pr); 
    }
    
    fclose(pr); 
    
    // 3. Проверка содержимого new1.txt
    rewind(pf); // Установка указателя pf на начало файла
    fgets(sl, 50, pf); 
    printf("Содержимое new1.txt: %s\n", sl); 
    
    // 4. Проверка содержимого new2.txt
    pr = fopen("new2.txt", "r"); 
    fgets(sl, 50, pr); 
    printf("Содержимое new2.txt (без пробелов): %s\n", sl); 
    
    fclose(pf); 
    fclose(pr);
    return 0;
}
```

## ✂️ Пример 2: Разбиение текста на массив слов

Этот пример показывает, как вручную прочитать текст из файла и разбить его на отдельные слова, сохраняя их в двумерный массив строк.

```c
#include <stdio.h>
#include <string.h>

int main(){
    FILE *f1;
    char st[80];             // Буфер для чтения строки
    char m[200][40];         // Массив для хранения слов
    int i, j = 0, n = 0;     // n - индекс слова, j - индекс символа в слове
    
    f1 = fopen("a.txt", "r");
    if (f1 == NULL) { printf("Ошибка открытия a.txt\n"); return 1; }
    
    // Чтение файла построчно
    while (fgets(st, 80, f1) != NULL) {
        
        for (i = 0; i < strlen(st); i++)
        {
            // 1. Если символ НЕ разделитель, добавляем его в текущее слово
            if (st[i] != ' ' && st[i] != '\n' && st[i] != '\r' && st[i] != '\t') { 
                m[n][j++] = st[i];
            }
            
            // 2. Обнаружен конец слова:
            // Текущий символ (st[i]) - не разделитель И (следующий символ st[i+1] - разделитель ИЛИ конец строки '\0')
            if (st[i] != ' ' && st[i] != '\n' && st[i] != '\r' && st[i] != '\t' && 
               (st[i+1] == ' ' || st[i+1] == '\n' || st[i+1] == '\r' || st[i+1] == '\t' || st[i+1] == '\0')) {
                
                m[n][j] = '\0'; // Завершаем текущее слово нулевым символом
                n++;            // Переходим к следующему слову
                j = 0;          // Сбрасываем счетчик символов
            }
        }
    } 
    
    fclose(f1);
    
    printf("Всего найдено слов: %d\n", n);
    for (i = 0; i < n; i++) puts(m[i]);

    return 0;
}
```

# 💾 11 Лекция: Обработка Двоичных (Бинарных) Файлов

## 🎯 Цель лекции

Приобретение теоретических знаний и практических навыков по созданию, чтению и модификации данных в **двоичных файлах**, используя функции **неформатированного ввода/вывода** (`fread`, `fwrite`) и **произвольного доступа** (`fseek`, `ftell`).

-----

## 1\. 💡 Основные понятия и преимущества

### Бинарный режим и точность

**Бинарный файл** — это файл, открытый в **двоичном режиме** (`"b"`), в котором не происходит никаких автоматических преобразований данных.

  * **Преимущество**: Идеально подходит для хранения сложных структур (записей), изображений или числовых данных. Двоичный режим гарантирует, что данные будут записаны и считаны **без потерь точности** (в отличие от текстового режима, где числа преобразуются в строки, что может привести к потере точности для чисел с плавающей точкой).
  * **Чтение/Запись**: Обычно данные читаются и записываются блоками (байтами), часто соответствующими размеру определенной структуры.

### Произвольный доступ (`Random Access`)

В отличие от текстовых файлов, которые часто обрабатываются последовательно, бинарные файлы могут быть обработаны с **произвольным доступом**.

  * **Произвольный доступ**: Возможность мгновенно переместить указатель чтения/записи к любому месту в файле.
  * **Механизм**: Осуществляется с помощью функции **`fseek()`**, которая позволяет обращаться с файлом как с **массивом** однотипных записей.

-----

## 2\. ⚙️ Функции неформатированного ввода/вывода

Для работы с блоками данных в бинарном режиме используются функции **`fread()`** и **`fwrite()`**.

### Запись в файл (`fwrite`)

Функция записывает блоки данных из памяти в файл.

```c
size_t fwrite(const void *ptr, size_t size, size_t count, FILE *f);
```

| Параметр | Описание |
| :--- | :--- |
| `ptr` | **Адрес** (указатель) первого элемента в памяти, который нужно записать. |
| `size` | **Размер** (в байтах) **одного** элемента. Часто используется `sizeof(struct)`. |
| `count` | **Количество** элементов (блоков) для записи. |
| `f` | Указатель на файловый поток (`FILE*`). |

**Возвращает**: Число фактически записанных элементов.

### Чтение из файла (`fread`)

Функция считывает блоки данных из файла в память.

```c
size_t fread(void *ptr, size_t size, size_t count, FILE *f);
```

| Параметр | Описание |
| :--- | :--- |
| `ptr` | **Адрес** (указатель) в памяти, куда нужно записать считанные данные. |
| `size` | **Размер** (в байтах) **одного** элемента. |
| `count` | **Количество** элементов для считывания. |
| `f` | Указатель на файловый поток (`FILE*`). |

**Возвращает**: Число фактически считанных элементов (обычно 1, если не конец файла, или 0 при достижении конца файла/ошибке).

-----

## 3\. 🧭 Функции произвольного доступа

Эти функции используются для перемещения указателя внутри файла.

### Перемещение указателя (`fseek`)

Устанавливает указатель текущей позиции в файле. Это позволяет перейти к нужному элементу (записи) без последовательного чтения всего файла.

```c
int fseek(FILE *f, long offset, int w);
```

| Параметр | Описание |
| :--- | :--- |
| `f` | Указатель на файловый поток. |
| `offset` | **Смещение** (в байтах) относительно точки отсчета `w`. Может быть положительным или отрицательным. |
| `w` | **Точка отсчета** (константа): |

| Константа | Значение | Точка отсчета |
| :--- | :--- | :--- |
| **`SEEK_SET`** | `0` | **Начало** файла. |
| **`SEEK_CUR`** | `1` | **Текущая** позиция указателя. |
| **`SEEK_END`** | `2` | **Конец** файла. |

**Пример использования при поиске**: Чтобы вернуться на одну запись назад после чтения структуры `t1` для ее изменения, используем:

```c
fseek(tf, -sizeof(t1), SEEK_CUR); // Смещение на размер t1 назад относительно текущей позиции
```

### Определение позиции (`ftell`)

Возвращает текущую позицию указателя в файле в виде смещения в байтах относительно начала.

```c
long int ftell (FILE *f);
```

## 💻 Пример: Обработка бинарного файла структур

Программа демонстрирует CRUD-операции (Создание, Чтение, Добавление, Поиск/Изменение) над бинарным файлом, содержащим структуры товаров.

### Структура данных

```c
struct tov {
    char name[10];
    float c;    // цена
    int kol;    // количество
} t1;
```

### Режимы работы с файлом

| Функция | Режим открытия | Назначение |
| :--- | :--- | :--- |
| `input` | `"wb"` | Создание нового файла (**W**rite **B**inary), стирает старое содержимое. |
| `print` | `"rb"` | Просмотр (чтение) файла (**R**ead **B**inary). |
| `app` | `"ab"` | Добавление в конец файла (**A**ppend **B**inary). |
| `find` | `"rb+"` | Чтение и запись (**R**ead **B**inary +), позволяет **изменять** данные. |

### Фрагмент функции `find` (Поиск и изменение)

В этой функции используется произвольный доступ для изменения найденной записи.

```c
void find(char *name)
{ 
    char c, tov[10]; 
    FILE *tf = fopen(name, "rb+"); // Открытие для чтения и записи
    if (tf == NULL) { /* ... */ return; }

    printf("Товар для поиска: ");
    scanf("%s", tov);

    // Цикл чтения структур
    while (fread(&t1, sizeof(t1), 1, tf)) // Читаем по одной структуре
    {
        if (strcmp(t1.name, tov) == 0) // Если нашли искомый товар
        {
            printf("Найден: %s, цена %6.2f, кол-во %d\n", t1.name, t1.c, t1.kol);
            printf("Изменить? y/n ");
            c = _getch(); 

            if (c == 'y')
            {
                // Считываем новые данные
                printf("Новое количество: "); scanf("%d", &t1.kol);
                printf("Новая цена: "); scanf("%f", &t1.c);

                // Произвольный доступ: возвращаем указатель на начало СЧИТАННОЙ записи
                // (fseek() смещает указатель на -sizeof(t1) байт назад относительно текущей позиции)
                fseek(tf, -sizeof(t1), SEEK_CUR); 
                
                // Записываем измененную структуру поверх старой
                fwrite(&t1, sizeof(t1), 1, tf); 
                
                // Очищаем буфер, чтобы изменения записались немедленно (важно для режима 'rb+')
                fflush(tf); 
            }
        }
    }
    fclose(tf);
}
```

# 🛠️ 12 Лекция: Передача, Перегрузка Функций и Структура Проекта

## 🎯 Цель лекции

Изучение продвинутых концепций организации кода в C++, включая **создание многофайловых проектов**, **передачу функций в качестве параметров** (через указатели) и **перегрузку функций** (polymorphism).

-----

## 1\. 📂 Создание и организация многофайлового проекта

Крупные программы разбиваются на несколько файлов (модулей) для улучшения организации, ускорения компиляции и облегчения совместной работы. Проект — это совокупность исходных файлов (`.c`/`.cpp`), заголовочных файлов (`.h`) и настроек, которые компилируются вместе в один исполняемый файл.

### 📝 Компоненты проекта

Простейший проект обычно включает:

1.  **Основной модуль (`main.cpp` / `prog.c`):** Содержит главную функцию `main()` и логику высокого уровня.
2.  **Модули реализации (`func.c` / `func.cpp`):** Содержат определения (реализации) конкретных функций, которые используются в других частях проекта.
3.  **Заголовочные файлы (`func.h`):** Содержат **объявления** (прототипы) функций и классов, а также объявления глобальных переменных и констант. Используются для информирования компилятора о существовании этих сущностей в других модулях.

### Объявления и определения

| Файл | Содержимое | Назначение |
| :--- | :--- | :--- |
| **`func.h`** | **Объявления** (`void sort(int *x);`) | Предоставляет интерфейс. Включается в файлы, использующие функции. |
| **`func.c`** | **Определения** (тело функции `void sort(int *x) { ... }`) | Содержит реализацию функции. Компилируется отдельно. |

### Управление глобальными переменными (`extern`)

При использовании одной и той же **глобальной переменной** в разных модулях необходимо применить ключевое слово `extern`:

1.  **Модуль, где выделяется память (например, `prog.c`):** Переменная объявляется **обычно** и здесь может быть инициализирована. Память выделяется именно здесь.
    ```c
    int m[] = {8, 2, 4, 1, 6, 5}; // Определение (выделение памяти)
    int N = sizeof(m) / sizeof(int); 
    ```
2.  **Модули, использующие переменную (например, `func.c`):** Перед объявлением ставится **`extern`**. Это сообщает компилятору, что переменная объявлена и память под нее выделена **в другом месте**.
    ```c
    extern int N; // Объявление (ссылка)
    ```

### Пример структуры проекта

| Файл | Содержимое |
| :--- | :--- |
| **`func.h`** | \`\`\`c
void swap(int \&x, int \&y);
void sort(int \*x);

````|
| **`prog.c`** | ```c
#include "func.h"
// Определение глобальной переменной N (выделение памяти)
int m[] = {8, 2, 4, 1, 6, 5};
int N = sizeof(m) / sizeof(int); 
int main() { ... sort(m); ... }
``` |
| **`func.c`** | ```c
#include <iostream.h>
// Ссылка на глобальную переменную N (память не выделяется)
extern int N; 
void swap(int &x, int &y) { ... }
void sort(int *x) { ... }
``` |

## 2. 🤝 Передача функции в качестве параметра

В C/C++ функции можно передавать в качестве аргументов другим функциям. Это реализуется с помощью **указателей на функции**. 

### Синтаксис объявления указателя на функцию

Указатель на функцию объявляется с указанием **типа возвращаемого значения** и **типов параметров** функции, на которую он указывает:

```c
int (*f) (int); // Объявление указателя 'f' на функцию, которая:
                // - возвращает int
                // - принимает int в качестве параметра
````

### Пример использования

Функция `call` принимает целое число `a` и указатель на функцию `f`. Внутри `call` происходит вызов функции, на которую указывает `f`.

```c
// Функция call: принимает целое 'a' и указатель 'f' на функцию (int, int)
int call (int a, int (*f) (int)) {
    // Вызов функции через указатель f(a)
    cout << "call " << " f(" << a << ") = " << f(a) << "\n";
    // Функция f (xx или yy) вызывается внутри call
} 

int main () {
    call(3, xx); // Передаем адрес функции xx
    call(4, yy); // Передаем адрес функции yy
}
```

  * При `call(3, xx)`, внутри `call` вызывается `xx(3)`.
  * При `call(4, yy)`, внутри `call` вызывается `yy(4)`.

## 3\. 🔄 Перегрузка функций (Function Overloading)

**Перегрузка функций** — это возможность иметь в одной области видимости несколько функций с **одним и тем же именем**, но с **разными списками параметров**. Это форма **полиморфизма** (множества форм).

### Правила перегрузки

Компилятор определяет, какую именно функцию вызвать, анализируя **сигнатуру** функции, которая включает:

1.  **Количество** параметров.
2.  **Тип** параметров.
3.  **Порядок** параметров.

> **Важно**: Тип возвращаемого значения **не участвует** в перегрузке. Функции должны отличаться по параметрам.

### Пример перегрузки имени `add`

```c
// Вариант 1: Два целых числа
int add(int a, int b) { 
   return(a + b); 
}

// Вариант 2: Три целых числа (отличается количеством параметров)
int add(int a, int b, int c) {
   return(a + b + c); 
}

// Вариант 3: Целое и число с плавающей точкой (отличается типом параметров)
// Примечание: В C++ часто используют float и double
int add (int a, float b) {
   return(a + (int)b); // или (int)(a + b); в зависимости от задачи
}

main(void) 
{ 
   cout << add(200, 101) << endl;         // Вызывается Вариант 1 (int, int)
   cout << add(100, 201, 700) << endl;     // Вызывается Вариант 2 (int, int, int)
   // При вызове с 700.1 (double) и 1 (int) компилятор ищет наиболее подходящий вариант.
   // В данном случае, это Вариант 3, где 700.1 будет неявно преобразовано к float.
   cout << add(700, 1.0f) << endl;         // Явно вызываем Вариант 3 (int, float)
}
```
